- Длина: медиана 1 923 знака (p25 1 178, p75 2 977, p90 4 831, максимум 16 186).
- 84 % — маркированный/нумерованный список (≥3 пунктов); 25 % — начинается с вердикта («Коротко…/Итог/Да/Нет»).
- Ссылки на источники: запросы с URL (n=23) — 87 % ответов ≥1 ссылки, 78 % ≥3 ссылок, таблицы 17 %; запросы-оценки без URL (n=29) — ссылки 14 %, таблицы 3 %; прочие без URL (n=37) — ссылки 24 %.
