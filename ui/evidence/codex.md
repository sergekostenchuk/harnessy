- **Только Codex.** Claude/Kimi/Hermes/Perplexity/Antigravity — вне этого источника. 142 импортированных транскрипта Claude Code (15–20.09; 3074 реплики в сыром виде) исключены из статистики и глубоко не читались.
- **Точность автоматики.** Проверена выборочно: классификатор сессий ≈85% (26/30); S2 «ты здесь/завис» — исходно 51% шума (слово «зависимость»), исправлено: 90 реплик вместо 224; S3 сужен до строгих форм (130 вместо 388); мат — 14/14 на выборке; M7 «не вижу» ≈80%; M9 «анимация/кокпит» ≈55%; M12 ≈70%; M4 «что от меня нужно» шумная (строгих форм — 6); остальные регулярки (I*, P*, E2–E4) не проверялись — читать как порядок величины. Разметка триггеров эмоций охватывает менее половины ругани.
- **Форки копируют историю с новым временем.** Дедуп по тексту (≥40 знаков) убрал 1037 копий (8,6%); короткие повторы не дедуплицированы; длительности в форках недостоверны (пример: 019fb55d — 109 ходов при wall = 1,0 ч).
