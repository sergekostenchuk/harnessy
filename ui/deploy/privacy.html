КонфиденциальностьPrivacy

Harnessy работает на вашем компьютере. Ключи остаются в системной связке ключей, переписка и файлы проекта — в папках пользователя. Сервис сайта хранит только данные, необходимые для входа и записи на альфа-тест.

Harnessy runs on your computer. Keys stay in the system keychain; conversations and project files stay in the user's folders. The website service stores only the data needed for sign-in and alpha registration.

Заявки на альфа-тестAlpha requests

Мы сохраняем имя, почту, необязательный логин GitHub, выбранные инструменты, ответ о наличии macOS, время заявки и необратимый хэш сетевого адреса. Это нужно только для отбора тестеров, связи по заявке и защиты формы от спама. Сырые сетевые адреса в таблицу заявок не записываются.

We store your name, email, optional GitHub username, selected tools, whether you have macOS, the request time, and a one-way hash of the network address. We use this only to select testers, contact you about the request, and protect the form from spam. Raw network addresses are not stored in the request table.

Чтобы удалить заявку, ответьте на письмо о заявке с той же почты и попросите удалить данные.

To delete your request, reply to the email about your application from the same address and ask us to remove the data.
