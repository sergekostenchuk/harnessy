## 2. Кривая эмоций и моменты истины

**Кривая (стадия → значение; в скобках — тип свидетельства).** 1 Импульс → **0** [вывод] (вопрос извне) / **+2** (поделиться после успеха, E4 — прямое; [смежное] E9) → 2 Провал ответа → **−2** [вывод] (прямая реплика, эмоция не кодирована) → 3 Запрос → **0…−1** [вывод] → 4 Ожидание → **0** (кодировка источника «нейтральная, рабочая», `r2-waiting.md` §4 Kimi эп. 1; связь эпизода с S10 — [гипотеза]; −1 — только фоновая гипотеза) → 5 Проверка → **−2…−3** [смежное: P4, П-08] или **+1…+2** [смежное: макет, узнавание]; прямых данных по S10 нет → 6 Передача → **0 [гипотеза]**, [нет свидетельств] → 7 Возврат вопроса → **−2** [вывод].

[вывод] Из семи значений прямыми свидетельствами S10 подкреплены два (+2 на импульсе Threads, отрицательная реплика сестры на стадиях 2 и 7); стадия 4 опирается на кодировку источника для эпизода, чья связь с S10 — гипотеза; остальные — выводы, смежные эпизоды или заглушки.
