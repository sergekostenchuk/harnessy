## 11. Термины-кандидаты (словарь `owner-vision.md §3.3` молчит)

- [термин-кандидат] **дайджест «к возвращению» / рекап** — сводка за время отсутствия (`_critic2.md §6 п.3`; `r2-waiting.md F12`: «рекап пока вас не было»).
- [термин-кандидат] **окно отсутствия** — период 06:00–13:00 МСК (`r2-waiting.md F7`).
- [термин-кандидат] **тип тишины** — «молчу по решению / не могу работать / жду тебя / лимит до … / сеть» (`_critic2.md §5 п.4`).
- [термин-кандидат] **зона ошибки** — «наша / провайдера / сеть / ваша» (`r2-screenshots.md F4`; `_critic2.md §5 п.8`).
- [термин-кандидат] **паспорт состояния** — «где · что · зачем · когда · что ожидаем · критерии успеха/провала · риски» (`claude-code.md §6.3`; `_critic.md §4 п.2`: «готовая структура паспорта состояния»).
