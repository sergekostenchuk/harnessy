# REVIEW — клип №6 «Полотно работы команды» (ru / en)

## Что это и как собрано
- Сюжет A «Кто чем занят» (STORY.md): один непрерывный дубль окна Harnessy — чат проекта (кадр 03 скетча 41) → клик по вкладке «Команда агентов» → полотно работы (кадр 01) → ряд карточек → живая стрелка → «+ роль» → меню (кадр 01·+) → пятая карточка «Тестер» встаёт в ряд → знак → финал. Каждый кадр вызван курсором.
- 21,6 с, 648 кадров, 1920×1080, 30 fps. Пять подписей в нижней полосе (Inter 600 52 px, одно–два слова коньяком), плашка «alpha» справа внизу весь клип, финал — знак Harnessy · alpha · «полотно команды».
- Визуал — DOM и CSS скетчей: панель A1 и полоска вкладок из clip-04 (скетч 40, `sidebar-v2.css`), полотно из `team-canvas.css` / `om-map.css` с данными `team-canvas.js` (роли, состояния, модели, библиотека ролей, очередь); геометрия стрелок считается в композиции теми же формулами, что в движке полотна (`workPath`: вертикальные кривые оргсхемы, полоса под карточками для живого сообщения), по измеренным размерам карточек — поэтому en-версия перерисовывает стрелки под свои ширины сама. Анимации CSS скетча (пульс «пишет», бегущий сектор, муравьи, hover-переходы) выключены — сектор «думает» и пунктир живой стрелки ведёт таймлайн линейно (постоянная скорость как состояние продукта).
- Плашки «макет» (План · карта, Путь, очередь, легенда, «Открыть конструктор →») сняты — запрет слова в кадре по SERIES.md.
- Два языка: 146 строк UI + 5 подписей + финал — переменные `data-var-text` (словарь `tools/vars.mjs`, скопирован из clip-04 и переписан); `node tools/vars.mjs en|ru` переключает набор хостов перед рендером. Позиции курсора (вкладка, карточка Ревьюера, «+ роль», пункт «Тестер», знак) берутся из DOM при сборке — en-курсор попадает в «Agent team», «Tester» без ручных координат. Сейчас проект в ru.
- Звук: UI-библиотека Pixabay из clip-01 (`assets/sfx/CREDITS.md`); музыки нет (как в clip-01/04). Клик по вкладке + «вшух» раскрытия полотна (1.7–1.8), «поп» живой стрелки (7.6), клик + «поп» меню (11.3–11.4), клик по «Тестер» (13.2), «вшух» сдвига карточек (13.5) и «поп» новой карточки (13.8, своя дорожка 5), клик по знаку (18.45), удар на финале (18.82).

## Что измерено, что только просмотрено

## Творческие решения и что не строилось
- Хук — не весь экран, а 1.9× на ленте чата + полоске: ответ помощника «Двое ждут вас…» читается (25.6 px), вкладка «Команда агентов» в том же кадре — курсор идёт к ней без лишнего наезда. Полотно потом раскрывается отъездом на весь экран.
- Полотно открывается с четырьмя ролями (+ оркестратор = «5 ролей»); Тестер — добавляется из меню и встаёт «свободно · без задачи» (состояние из дизайн-кода team-canvas-spec). В скетче 41 Тестер нарисован шестым со статусом «ошибка»; здесь он новый — так действие «+ роль» показывает результат.
- Живая стрелка приходит как событие (7.6 с) — до неё Воркер 1 «пишет» и в карточке оркестратора сказано «сдача уйдёт ревьюеру с минуты на минуту»; подпись стрелки «… · сейчас» вместо «2 мин» скетча. Реплики оркестратора и ответ в чате — текст клипа по данным скетча.
- Наведение на карточку Ревьюера — только подъём на 2 px и тень (правило :hover скетча); цвет рамки оставлен коньячным (в скетче :hover красит рамку серым — потерялся бы смысл «ждёт решения»).
- Очередь задач внизу — оставлена как в кадре 01, без плашки «макет», курсор к ней не подходит.
- Сюжеты B («стрелка первой») и C («очередь → карточка») не строились — причины в STORY.md.

## Самый слабый кадр и что изменить при наличии времени
- Отъезд 13.3–13.9 совпадает со сдвигом карточек 13.5–14.1: два движения в одном такте — на общем плане сдвиг читается, но посадка Тестера (13.8–14.15) приходится на хвост отъезда. Вариант: задержать сдвиг до 13.9 и дать Тестеру 0.3 с тишины перед подписью.
- Пунктир живой стрелки на 1.0× (14.7 с) — 2 px, в телефонном листе почти не виден; на крупном плане (1.9×) читается.
- Финал без призыва к действию — по заданию только знак + alpha + подпись клипа.
