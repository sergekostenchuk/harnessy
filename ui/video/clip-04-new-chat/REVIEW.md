# REVIEW — клип №4 «Новый чат → проект» (ru / en)

## Что это и как собрано
- Сюжет A «Кофе, потом дело» (STORY.md): один непрерывный дубль окна Harnessy (скетч 40, кадр A1 → A1·c) на холсте дизайн-кода; камера ходит композер → лента → «В проект ▾» → панель; каждый кадр вызван курсором. Помощник сам подводит к действию: на рабочий вопрос отвечает «этот чат без проекта, материалов не вижу — добавьте чат в проект».
- 21,6 с, 648 кадров, 1920×1080, 30 fps. Пять подписей в нижней полосе (Inter 600 52 px, одно слово коньяком), плашка «alpha» справа внизу весь клип, финал — знак Harnessy · alpha · «новый чат → проект».
- Визуал — DOM и CSS скетчей: панель A1 и шапка без полоски с «В проект ▾» (`40-sidebar.html`, `sidebar-v2.css`), состояния кнопки и карточка подтверждения из дизайн-кода (`00-design-code.html`, секция sidebar-v2-spec: нет проекта · выбор · подтверждение · «переносим…» · «перенесено в Alpha-Test»), разметка сообщений `.me/.ai/.thought` из `01-chat.html`, проектная полоска A1·c. Тег «макет» у «План · карта» и «Путь» снят (запрет слова в кадре). Анимации CSS скетча выключены — всё ведёт таймлайн.
- Два языка: 106 строк — переменные `data-var-text` (словарь `tools/vars.mjs`, скопирован из clip-01 и переписан под этот клип); `node tools/vars.mjs en|ru` переключает набор хостов перед рендером. Печать и позиции курсора берутся из DOM в момент сборки (`getBoundingClientRect` до трансформаций), поэтому в en-версии курсор попадает в «To project», «Alpha-Test», «Move» без ручных координат.
- Звук: UI-библиотека Pixabay из clip-01 + `typing.mp3` / `key-press.mp3` из той же библиотеки скилла media-use (`assets/sfx/CREDITS.md`); музыки нет (как в clip-01: HeyGen исключён владельцем, локального генератора нет).

## Что измерено, что только просмотрено
- `npx hyperframes check --json`: ok=true, 0 ошибок (lint, runtime, layout, motion, contrast). Первый прогон дал 4 `content_overlap` — меню и карточка «В проект» поверх текста ленты (так и задумано: меню лежит над чатом, как в скетче); участники помечены `data-layout-allow-overlap`, меню/карточка — `data-layout-allow-occlusion`.
- Предупреждения оставлены намеренно: `text_below_floor` (118 элементов UI продукта 9–13 px в обзорных кадрах 1:1 и 1.28× — интерфейс, не титры; крупные планы 1.6–2.2× дают 24–30 px); `line_unread` — печатаемый текст (символы появляются по одному, аудитор считает каждый символ словом), плейсхолдер «Написать сообщение…» (0.2 с до начала печати), «думал 0,6 с» (виден 2–5 с, но аудитор померил кадр с уходом камеры), строки панели в финальном пролёте камеры (0.1–0.16 с под размытием).
- Контраст: третичный #88888f (как в clip-01) — AA пройден на всех 5 точках.
- `snapshot --review`: 9 битов (0.3 / 3.6 / 8.8 / 9.4 / 10.8 / 14.1 / 16.3 / 19.15 / 20.2 с), шов ui→end (18.65–19.05), телефон 360 px — просмотрены; подписи читаются при 360 px, UI — нет (ожидаемо).
- Отдельно просмотрены: отправка (2.5–3.2 с, 8 кадров) — композер уезжает вниз, центр гаснет, пузырь поднимается, камера уходит на ленту; шапка → полоска + переезд строки (15.4–16.3 с, 8 кадров) — шапка гаснет, полоска вытирается слева направо, строка «как заварить кофе в турке» встаёт над «Кто ты?…», счётчики 3→4 и 2→1, «чаты без проекта» без наложений.
- Рендеры: `renders/new-chat-ru.mp4`, `renders/new-chat-en.mp4` — ffprobe 21.600 с каждый, h264 1920×1080 30 fps + AAC; кадры декодированы из mp4 (`renders/frames/`) и просмотрены (ru 3.7 / 10.8 / 16.6 с; en 3.7 / 10.8 / 12.6 / 16.6 с).
- Звук измерен (`npx hyperframes audio`), не прослушан: onsets 1.045 (клик + печать), 2.645 (отправка), 3.565 (ответ), …, пик 18.89 (удар на знаке); −18.7 LUFS integrated, true peak −8.8 dBTP, клиппинга нет.

## Творческие решения и что не строилось
- Перенос — в существующий проект Alpha-Test (пункт «текущий»), а не «Сделать проектом…»: для переноса в дизайн-коде нарисованы все состояния (подтверждение, «переносим…», «перенесено в Alpha-Test», полоска, переезд строки под «чаты · Alpha-Test»); для «новой папки» экран подтверждения и имя папки не нарисованы. Пункт «Сделать проектом…» виден в меню.
- Рабочий вопрос «Теперь по делу: что осталось до запуска Alpha-Test?» и ответ помощника «материалы Alpha-Test мне не видны — добавьте чат в проект» — текст клипа, не из скетчей (в скетчах нет ответов самостоятельного чата). Ответ про кофе — короткий бытовой, три строки.
- Счётчик вкладки «Чат 4» и «чаты · Alpha-Test 4» — 3 чата скетча + перенесённый.
- Сюжеты B («две жизни одного чата», до/после) и C («строка переезжает», результат первым) не строились — причины в STORY.md.

## Самый слабый кадр и что изменить при наличии времени
- Отправка первого вопроса (2.6–3.1 с): композер «Нового чата» уезжает вниз и гаснет, но его посадка на место композера чата остаётся за кадром (камера уже на ленте) — морф «контейнер → контейнер» читается только наполовину. Вариант: задержать наезд на 0.3 с, чтобы зритель увидел композер внизу, затем подняться к пузырю.
- Наезд 2.2× на «В проект ▾»: слева текст ответов обрезан краем кадра (неизбежно при фокусе на правом верхнем углу); можно приглушить ленту на 30 % на время меню.
- Финал без призыва к действию — по заданию только знак + alpha + подпись клипа.
