# REVIEW — клип №9 «Режим общения» (ru / en)

## Что это и как собрано
- Сюжет A «Подумать вслух, потом сделать» (STORY.md): один непрерывный дубль окна Harnessy (чат проекта Alpha-Test: панель A1 и проектная полоска A1·c из скетча 40, лента из 01-chat, композер варианта (в) из скетча 41) на холсте дизайн-кода; камера ходит композер → лента → композер → лента → весь экран; каждый кадр вызван курсором. Доказательство тумблера — контраст двух ответов на один вопрос: с включённым «Обсуждение» — рассуждение с чипом «обсуждение» (плюс, минус, встречный вопрос), ни одной строки действия; после выключения и «делай» — ответ без чипа и карточка «Действия» со строками «Запись файла · …».
- 20,6 с, 618 кадров, 1920×1080, 30 fps. Пять подписей в нижней полосе (Inter 600 52 px, одно слово коньяком), плашка «alpha» справа внизу весь клип, финал — знак Harnessy · alpha · «режим общения».
- Визуал — DOM и CSS скетчей: панель и полоска (`40-sidebar.html`, `sidebar-v2.css`, через общий CSS семьи из clip-04), лента `.me/.ai/.thought/.card/.chk` (`01-chat.html`), переключатель «Чат · Команда» (`.tc-seg`) и тумблер «Обсуждение» (`.tc-tg` + `.tog`, `team-canvas.css`, `team-canvas.js` composer({v:'c'})), иконка режима `talk` из team-canvas.js. Анимации CSS скетча выключены — всё ведёт таймлайн.
- Лента «прокручена к концу»: колонка сообщений прижата к композеру и при каждой отправке уезжает вверх (как в живом чате) — так крупный план композера и ленты заполнен, а не висит над пустотой.
- Два языка: 69 строк — переменные `data-var-text` (словарь `tools/vars.mjs`, скопирован из clip-04 и переписан под этот клип); `node tools/vars.mjs en|ru` переключает набор хостов перед рендером. Печать и позиции курсора берутся из DOM в момент сборки, поэтому в en-версии курсор попадает в «Everything, no questions», «Discussion», поле и кнопку отправки без ручных координат.
- Звук: UI-библиотека Pixabay из clip-01/04 (`assets/sfx/CREDITS.md`): клики на тумблере/поле/отправке/знаке, печать, «поп» на ответах, чипе и карточке действий, «вшух» на отъезде, низкий удар на знаке; музыки нет (как во всей серии).

## Что измерено, что только просмотрено
- `npx hyperframes check --json`: ok=true, 0 ошибок (lint, runtime, layout, motion, contrast).
- Предупреждения оставлены намеренно: `contrast_aa_failure` — белая «✓» 9 px в зелёном кружке карточки действий (собственный стиль `.ok` из 01-chat, значок, а не читаемый текст; 107/108 проверок контраста пройдены); `text_below_floor` (81 элемент UI продукта 9–13 px в обзорных кадрах 1:1 — интерфейс, не титры; крупные планы 1.9× дают 23–26 px); `line_unread` — печатаемый вопрос (символы появляются по одному, аудитор считает каждый символ словом) и строки панели в финальном пролёте камеры (0.1–0.13 с под размытием).
- `snapshot --review`: 9 битов (0.3 / 0.8 / 3 / 6.8 / 8.9 / 10 / 13.3 / 18.15 / 19.2 с), шов ui→end (17.65–18.05), телефон 360 px — просмотрены; подписи читаются при 360 px, UI — нет (ожидаемо).

## Творческие решения и что не строилось
- Хук — курсор задерживается на чипе прав «Всё без вопросов» (помощник сейчас «делает»), подпись «Поговорить, не трогая проект» — «думает вслух» за зрителя; тумблер включается следующим кликом.
- Чип «обсуждение» на ответе: в дизайн-коде нарисованы тумблер, переключатель и меню прав, самого чипа на сообщении нет — собран из пилюли продукта `.pill.acc` (как «входящие 2») с иконкой режима `talk`. Вопрос владельцу.
- Карточка «Действия» — `.card` + ряды `.chk` из 01-chat (там «integration · идёт…» → «✓»); тексты «Запись файла · src/intake/invoice.test.ts» / «…invoice.ts» — текст клипа. Крутилка «идёт» — статичное кольцо (запрет вращения/пульса на UI).
- Тексты сообщений («Что сейчас делает команда?», ответ про TS-35 и прогон H1.5, вопрос про модуль приёма накладной, рассуждение, «Начинаю…») — текст клипа по мотивам 01-chat; в скетчах ответа в режиме обсуждения нет.
- Сюжеты B («два ответа рядом», до/после) и C («файл, который не изменился», результат первым) не строились — причины в STORY.md.

## Самый слабый кадр и что изменить при наличии времени
- Включение тумблера (2.45–2.65 с): кнопка едет 10 px и чип подсвечивается — на крупном плане читается, но событие тихое для ключевого момента клипа; вариант: короткий наезд камеры 1.9→2.3× на строку чипов за 0.4 с перед кликом, затем назад к полю.
- Между ответом-рассуждением (6.05) и выключением тумблера (9.5) 3.4 с одна картинка: ответ + подпись 3 — читать есть что (22 слова), но движения нет; можно подвести курсор к чипу «обсуждение» на 7.5 с.
- Финал без призыва к действию — по заданию только знак + alpha + подпись клипа.
