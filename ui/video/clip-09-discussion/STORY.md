# Клип №9 «Режим общения» — сюжеты

Одна вещь: «В чате проекта есть тумблер «Обсуждение»: пока он включён, помощник только думает вместе с вами — взвешивает, задаёт встречный вопрос — и не трогает ни один файл; выключили — он снова делает».
Что запомнить: «можно поговорить с помощником о проекте, не боясь, что он что-то сломает».
Один зритель: обычный человек в рабочем чате проекта; у него есть мысль «а если переписать модуль?», но он не хочет, чтобы помощник бросился переписывать.
Факты только из скетчей: `41-team-canvas.html` вариант (в) — переключатель вида «Чат · Команда» над композером и тумблер «Обсуждение» в строке чипов рядом с правами (`team-canvas.js` composer({v:'c'}), `team-canvas.css` .tc-seg / .tc-tg); `00-design-code.html` секция team-canvas-spec («режим общения = «Только обсуждение», у движка — chat: агент обсуждает, ничего не делает»; меню прав с пунктом «Только обсуждение»); `40-sidebar.html` кадр A1·c — панель и проектная полоска; `01-chat.html` — разметка .me / .ai / .thought / .card / .chk (строки действий «идёт…» → «✓»). Данные: Alpha-Test, Анна Ветрова, you@example.com, чаты примера.

## Три сюжета

### A. «Подумать вслух, потом сделать» — ВЫБРАН
- Приём: момент в чьём-то дне (одна и та же мысль дважды: сначала обсуждаем, потом делаем); форма: один непрерывный дубль, камера ходит композер → лента → композер → лента → общий план; каждый кадр вызван курсором.
- Первые 2 с: чат проекта Alpha-Test 1:1 (панель, полоска, лента с одним обменом, композер варианта (в)); курсор въезжает справа к строке чипов, камера наезжает на композер; курсор задерживается на чипе прав «Всё без вопросов» (сейчас помощник делает), подпись «Поговорить, не трогая проект».
- Биты: hook (чип «Всё без вопросов» под курсором — помощник в режиме «делает») → клик по тумблеру «Обсуждение», он загорается коньяком, подпись «Помощник только обсуждает. Ничего не меняет» → печатается «а если переписать модуль приёма накладной?» → ответ с чипом «обсуждение»: плюс, минус, встречный вопрос; ни одной строки действия (подпись «Плюсы, минусы, вопрос — без действий») → тумблер выключен (подпись «Выключили — можно делать») → «делай» → ответ без чипа и карточка действий: «Запись файла · src/intake/invoice.test.ts ✓ 0,4 с», «Запись файла · src/intake/invoice.ts · идёт…» (подпись «Сказали «делай» — делает») → отъезд на весь экран → клик по знаку → финал Harnessy · alpha · «режим общения».
- Вид: графит #101012 / панели #141416 / #1b1b1e, коньяк #c27a34 только там, где он есть в продукте (включённый тумблер, чип «обсуждение», чипы композера, вкладка «Чат», бейдж «Артефакты 3», крутилка «идёт») плюс одно слово в каждой подписи; Inter / JetBrains Mono.
- Звук: без музыки; клики, печать, «поп» на ответах и чипе, «вшух» на отъезде, низкий удар на знаке.
- Почему: зритель видит ровно свою ситуацию — хочется обсудить, не ломая; контраст двух ответов на один и тот же вопрос («обсуждение» без действий ↔ карточка действий) доказывает тумблер лучше любых слов; все состояния нарисованы в дизайн-коде, выдуманных экранов нет.

### B. «Два ответа рядом» (не строился)
- Приём: «до и после»; форма: разделённый экран сходится в один. Один и тот же вопрос «а если переписать модуль?» отправлен в два чата: слева тумблер включён — рассуждение с чипом «обсуждение»; справа выключен — карточка действий растёт строка за строкой. Панели сходятся в один чат с тумблером.
- Риск: два окна приложения в кадре 1920 мельчат текст сообщений ниже 20 px; зритель не видит причину (клик по тумблеру) — только следствие.

### C. «Файл, который не изменился» (не строился)
- Приём: результат первым; форма: цепочка объект→объект. Первый кадр — крупно вкладка «Артефакты»: список файлов, у каждого «изменён 2 ч назад», ничего не меняется, пока в чате идёт разговор; камера отъезжает — виден тумблер «Обсуждение» и рассуждение помощника; потом тумблер выключен — в списке появляется «изменён только что».
- Риск: экран списка файлов с временем изменения в скетчах не нарисован — пришлось бы выдумывать; смелый, но требует экрана, которого нет.

## Допущения
- Длительность 20,6 с (в окне 18–22), 1920×1080, 30 fps, подписи-титры без озвучки, музыки нет.
- Вариант (в) из скетча 41 — по заданию (переключатель «Чат · Команда» над композером, тумблер «Обсуждение» в строке чипов). Пункт «Только обсуждение» в меню прав (вариант (а)) в кадр не попадает — это другой вариант того же режима.
- Чип «обсуждение» на ответе: в дизайн-коде нарисованы тумблер, переключатель и меню прав; самого чипа на сообщении там нет — он собран из пилюли продукта (`.pill.acc`, как «входящие 2») с иконкой режима `talk` из team-canvas.js. Вопрос владельцу в отчёте.
- Строка действия — карточка `.card` с рядами `.chk` из 01-chat.html (там «integration · идёт…» → «✓»); текст «Запись файла · путь» — текст клипа.
- Плашка «alpha» в правом нижнем углу весь клип — требование владельца.
