# Клип №1 «Боковая панель и рейка» — сюжеты

Одна вещь: «Слева в Harnessy — только проекты и чаты; всё остальное — по наведению, в профиле и в рейке».
Что запомнить: «панель = проекты и чаты, рейка = та же панель, сжатая».
Один зритель: пришёл из Claude Code / Codex / Antigravity, открыл Harnessy первый раз, видит «Новый чат» и ведёт курсором по панели.
Факты только из скетча `ui/sketches/disarto/40-sidebar.html` (кадр A1): данные Alpha-Test, Анна Ветрова, you@example.com, чаты, лимиты 64 % / 91 %.

## Три сюжета

### A. «Один экран, один курсор» — ВЫБРАН
- Приём: курсор как персонаж; форма: один непрерывный дубль — камера ходит между всем окном, панелью и крупным планом одного элемента, ни одной склейки до финала.
- Первые 2 с: весь экран «Новый чат» 1:1 с панелью слева; рабочая область чуть гаснет, панель остаётся яркой; подпись «Слева — проекты и чаты. Больше ничего.»; курсор въезжает справа.
- Биты: hook (экран, панель) → Входящие (наезд, наведение) → клик «Другие проекты» → наведение на проект → меню проекта → клик профиля → меню вверх с Автопилотом → отъезд, клик ⟨ → панель сжимается в рейку → наезд на рейку, подсказка → клик по знаку в рейке → знак вырастает в финальную карточку Harnessy · alpha.
- Вид: графит #101012, панели #141416/#1b1b1e, коньяк #c27a34 только там, где он есть в продукте, плюс одно слово в каждой подписи; Inter / JetBrains Mono.
- Звук: без музыки (бесплатного локального генератора нет), UI-звуки на действиях: клики, «поп» меню, «вшух» сжатия, низкий удар на знаке.
- Почему: незнакомец следит за курсором и видит причину каждого следующего кадра; каждая сцена задания — одно действие в реальном интерфейсе; ни одной выдуманной картинки.

### B. «Из трёх окон — в одну панель» (не строился)
- Приём: «жизнь до и после»; форма: разделённый экран сходится в один. Сначала три абстрактных окна терминалов дёргаются (без названий конкурентов), затем панель Harnessy спокойно держит проекты и чаты; далее те же пять действий, но короче.
- Риск: окна «до» пришлось бы рисовать (нет источника) — нарушение правила «реальный UI, не макет»; сюжет про сравнение, а не про то, как панель работает.

### C. «Рейка раскрывается» (не строился)
- Приём: «результат первым»; форма: цепочка объект→объект. Первый кадр — узкая рейка; клик ⟩ раскрывает её в панель; каждое меню становится следующим кадром; финал — сжатие обратно.
- Риск: первый кадр для новичка непонятен (узкая полоска иконок), а цель клипа — объяснить панель за 20 с; смелый, но хуже читается с первого раза.

## Допущения
- Длительность 21,3 с (в окне 18–22), 1920×1080, 30 fps, подписи-титры без озвучки.
- Плашка «alpha» в правом верхнем углу всего клипа — требование владельца (альфа-версия продукта), оставлена намеренно.
- Музыка: HeyGen исключён владельцем; локальный MusicGen не установлен (нет torch) — клип без музыкальной подложки; UI-звуки — встроенная библиотека Pixabay (без атрибуции).
