# REVIEW — клип №1 «Боковая панель и рейка» (ru / en)

## Что это и как собрано
- Сюжет A «Один экран, один курсор» (STORY.md): один непрерывный дубль окна Harnessy (скетч 40, кадр A1) на холсте дизайн-кода; камера ходит между всем окном и крупными планами; каждый следующий кадр вызван действием курсора; финал — клик по знаку в рейке → карточка Harnessy · alpha.
- 21,6 с, 648 кадров, 1920×1080, 30 fps. Подписи-титры в нижней полосе 168 px (Inter 600 52 px, одно слово коньяком), плашка «alpha» в правом нижнем углу полосы весь клип (кроме финала, где «alpha» — в лок-апе).
- Визуал — статичный DOM скетча `ui/sketches/disarto/40-sidebar.html` (панель A1, рейка, меню проекта, меню профиля с Автопилотом, рабочая область «Новый чат») с CSS `sidebar-v2.css` (:hover → управляемые классы, анимации/переходы убраны — всё ведёт таймлайн). Иконки — набор скетча. Знак финала — `ui/desktop/icon.icns` (PNG 1024).
- Два языка: все 100 строк — переменные `data-var-text` (словарь в `tools/vars.mjs`); `node tools/vars.mjs en|ru` переключает набор хостов перед рендером (корневая переменная не доходит до сцен в компиляторе рендера — проверено, см. ниже).

## Что измерено, что только просмотрено
- `npx hyperframes check --json`: ok=true (0 ошибок). Оставленные предупреждения: `text_below_floor` для ~120 элементов UI (текст продукта 13 px в обзорных кадрах 1:1 — это интерфейс, не титры; крупные планы 1.75–2.2× дают 22–29 px); `line_unread` для строк UI, уходящих из кадра при движении камеры (не титры). Намеренные opt-out: рейка под панелью (`data-layout-allow-occlusion` у панели, `data-layout-ignore` у глифов рейки), меню поверх списка (`data-layout-allow-overlap` у списка панели), усечённые «…» строки чатов (`data-layout-bleed`).
- Контраст: третичный цвет для видео поднят с #66666e (токен продукта) до #88888f, чтобы пройти AA 4,5:1 на панели/raised/tile. Токен продукта не менялся.
- `snapshot --review`: биты (0.3 / 0.6 / 4.4 / 8.85 / 9.4 / 12.25 / 16.3 / 19.15 / 20.2 с), шов ui→end (18.65–19.05), телефонная ширина 360 px — просмотрены; подписи при 360 px читаются, текст UI — нет (ожидаемо).
- Сжатие панели в рейку: `snapshot --range 15.1,15.9 --frames 8` — панель вытирается clip-path, рабочая область сдвигается синхронно, рейка открывается под ней; скачков нет.
- Рендеры: `renders/sidebar-ru.mp4`, `renders/sidebar-en.mp4` — ffprobe 21.600 с каждый, h264 1920×1080 30 fps + AAC. Кадры декодированы из mp4 (`.hyperframes/artifacts/decoded/`) и просмотрены.
- Звук измерен (`npx hyperframes audio`), не прослушан: пики на 7.29 / 8.44 / 11.69 / 15.19 / 16.54 / 18.49 / 18.87 с совпадают с кликами (7.25, 11.65, 15.15, 18.45), появлением меню (8.4, 16.5), сжатием (15.2) и посадкой знака (18.85) — через 1 кадр после картинки; −16.5 LUFS integrated, true peak −8.8 dBTP, клиппинга нет. Музыкальной подложки нет: HeyGen исключён владельцем, локального MusicGen (torch) на машине нет — SFX из встроенной библиотеки Pixabay (лицензия без атрибуции, `assets/sfx/CREDITS.md`).
- Английская версия: кадры 9.6 / 13 / 17 с проверены на снимках и в декодированном mp4 — все пункты панели/меню/подписей по-английски; подпись Автопилота укорочена, чтобы меню влезало в кадр.

## Творческие решения и что не строилось
- Окно 1600×900 на холсте дизайн-кода (графит + точечная сетка, радиус 18, тень) — это собственная подача скетчей, а не «пустота с мелким UI»: при 1:1 окно занимает 83 % ширины кадра.
- Меню проекта показано на первой строке «Других проектов» (chat-test), не на harnessy-test как в кадре скетча: так меню входит в окно без переворота вверх, а счётчик «Команда агентов» совпадает со строкой (8 ролей).
- Сюжеты B («до/после с тремя окнами») и C («рейка раскрывается») не строились — причины в STORY.md.

## Самый слабый кадр и что изменить при наличии времени
- Сцена 1 (0–3.3 с, окно 1:1): текст панели 13 px — новичок видит структуру (слева панель, справа чат), но не читает строки. Вариант: начать с окна 1.15× и обрезанным правым краем, или держать сцену 1 на 0.5 с дольше.
- Сцена 3 (8.4–11 с): курсор стоит на chat-test, а подпись говорит «наведите на проект» — в кадре нет самого движения наведения крупно (оно происходит во время наезда). Вариант: задержать наезд на 0.2 с, чтобы наведение читалось уже в крупном плане.
- Финал: нет призыва к действию (команды/кнопки) — по заданию только логотип + alpha.

## Предупреждения, оставленные намеренно
- `text_below_floor` (UI продукта), `line_unread` (UI, уходящий из кадра) — см. выше.
- Плашка «alpha» в углу всего клипа — требование владельца (BANNED-список запрещает «логотип в углу», но это бейдж версии, не логотип).

## Как продолжить

- Тексты: `tools/vars.mjs` (словарь ru/en) → `node tools/vars.mjs ru|en` → рендер.
