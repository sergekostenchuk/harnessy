# REVIEW — клип №2 «Автопилот» (ru / en) — главный клип серии

## Что это и как собрано
- Сюжет A «Одна ночь» (STORY.md): момент из жизни — вечер 22:40 → ночь → утро 07:00, один непрерывный дубль окна Harnessy; каждая смена кадра вызвана курсором или течением времени (заливка холста + метка времени на полосе подписей).
- 24,8 с, 744 кадра, 1920×1080, 30 fps. Подписи-титры в полосе 168 px (Inter 600 52 px, одно слово коньяком), метка времени слева внизу, плашка «alpha» справа внизу (кроме финала).
- Один вопрос идёт через весь клип: «перевести воркера на Sonnet или ждать сброса Codex» (карточка «решение» скетча 40) — вечером ждёт во Входящих (2·4) → ночью по нему советуются оркестратор и ревьюер → решение с «почему» → утром лежит в Входящих «автопилот решил · 3» с «Отменить / Хорошо».
- Визуал — DOM и CSS скетчей: панель A1 и меню профиля с Автопилотом (40-sidebar + sidebar-v2.css; состояние выкл → «до утра · 07:00», тумблер .ps2-tg), рабочая область «Новый чат» (A1), полотно команды (41-team-canvas: .tc-orch compact, .tc-card ревьюера, живая стрелка коньяком), лента Входящих с карточками .ps2-ib (A1·i). Тексты решений — из данных скетча (IB_NEED / IB_INFO / .decide: 19:58, 0,3 % недели, 7/7 зелёный, резерв VPS NL99).
- Два языка: 139 строк — переменные `data-var-text`, словарь `tools/vars.mjs` (скопирован из clip-01, заполнен заново); `node tools/vars.mjs en|ru` → рендер.
- Переходы (4 вида, все с причиной): наезды камеры на действие курсора; заливка холста (вечер → ночь → утро) с меткой времени; blur-swap на одной сцене (Новый чат → Команда агентов по включению Автопилота; Команда → Входящие по клику «Входящие»); зум сквозь знак в панели → финальная карточка.

## Исправлено по ходу (что нашли снимки)
- Унаследованный `#ui-main` шириной 1544 px (в clip-01 он сдвигался при сжатии панели) — лента Входящих и «Чем займёмся?» были смещены вправо, EN-карточки вылезали за окно → ширина 1340 px, сдвиг `#ui-nc` убран.
- У второго курсора (утро) не было CSS — рисовался белой полосой внизу окна → правила добавлены.
- Пилюля «◆ автопилот · до 07:00» стояла справа в шапке полотна и не попадала в ночной кадр → перенесена к заголовку.
- Рамки камеры: ночь — виден верх с пилюлей (ry 0), утро — виден заголовок ленты с фильтрами (1.8× от левого края рабочей области).
- Шапка «В проект ▾ · подключено» была под полосой заголовка (z-index) → поднята.

## Творческие решения и что не строилось
- Время суток — не в окне продукта (в скетчах нет часов), а на полосе подписей рядом с «alpha»: метка «22:40 · вечер» → «23:52 · ночь» → «01:12» → «03:40» → «07:00 · утро». Окно продукта не меняется, меняется холст под ним.
- Ночь показана на полотне команды (скетч 41) с единственным добавленным элементом — пилюлей состояния Автопилота в шапке (состояние взято из меню профиля скетча 40). Вынесено в вопросы владельцу.
- Карточки решений ночью — те же `.ps2-ib`, что утром в Входящих: зритель узнаёт их утром.
- Утром курсор сначала наводится на «Отменить» (рамка), потом нажимает «Хорошо» — так показаны обе двери без второго клика.
- Сюжеты B («Два утра», до/после) и C («От карточки назад к вечеру», обратная хронология) не строились — причины в STORY.md.

## Самый слабый кадр и что изменить при наличии времени
- Ночь 9.3–10.6 с: две карточки сверху и пустое полотно снизу 1,3 с до первой карточки решения. Вариант: начать ночь наездом 2.4× только на две карточки и отъехать до 2.0× вместе с посадкой первого решения.
- Шов 22.0–22.1: один кадр затемнения до 70 % + первый кадр финала (знак ещё при opacity 0) — читается как dip cut; можно начать финал на 0.1 с раньше поверх затемнения.
- Утро: кнопки «Отменить / Хорошо» видны 2 с (18.8–20.85); если владелец хочет дольше держать выбор — сдвинуть клик «Хорошо» на +0.4 с, укоротив удержание ночи (15.0–16.6).

## Предупреждения, оставленные намеренно
- `text_below_floor` («W» лимитов), `line_unread` (UI, уходящий из кадра; карточка №3 на кадре входа) — см. выше.
- Плашка «alpha» в углу весь клип — требование владельца.
