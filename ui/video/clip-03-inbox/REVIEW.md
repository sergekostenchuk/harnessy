# REVIEW — клип №3 «Входящие» (ru / en)

## Что это и как собрано
- Сюжет A «Одна карточка — до конца» (STORY.md): один непрерывный дубль окна Harnessy (скетч 40, кадры A1 → A1·i); камера ходит между всем окном, панелью, обзором ленты и одной карточкой; каждый следующий кадр вызван курсором; финал — клик по знаку в шапке панели → карточка Harnessy · alpha.
- 19,3 с, 579 кадров, 1920×1080, 30 fps. Подписи-титры в нижней полосе (Inter 600 52 px, одно слово коньяком), плашка «alpha» в правом нижнем углу весь клип (кроме финала, где «alpha» — в лок-апе).
- Визуал — статичный DOM скетча `ui/sketches/disarto/40-sidebar.html` (панель A1, экран «Новый чат», экран «Входящие»: шапка с фильтрами «Все 6 · Требует действия 2 · К сведению 4», шесть карточек `.ps2-ib` всех видов) с CSS `sidebar-v2.css` (база — композиция clip-01, :hover → управляемые классы, переходы убраны). Знак финала — `assets/img/harnessy-icon.png` из clip-01.
- Ответ прямо в карточке — новое состояние, которого в скетче 40 нет: блок решения из 01-chat (`.decide`: «нужно ваше решение · 40 мин», текст, кнопки «Перевести на Sonnet» · «Ждать сброса») раскрывается внутри карточки «решение» по клику «Ответить». Тот же вопрос, что в карточке; кнопок и экранов, которых нет в скетчах, не добавлено.
- «Выполнено»: кнопки гаснут, зачёркивание слева направо, рамка → серая, «выполнено» зелёным (состояние `.done` из скетча), карточка переезжает вниз ленты под «обновление» (transform y, соседи подтягиваются), заголовки групп «2 → 1», «4 → 5», бейдж панели «2 · 4 → 1 · 5», чипы фильтра — вертикальный сдвиг цифры.
- Два языка: все 105 строк — переменные `data-var-text` (словарь `tools/vars.mjs`); `node tools/vars.mjs en|ru` переключает набор хостов перед рендером (как в clip-01). Проект оставлен в ru.

## Что измерено, что только просмотрено
- `npx hyperframes check --json`: ok=true (0 ошибок) на финальных байтах. Исправлено до: контраст метки «подключение» (цвет ошибки #c9566e → #cf5c75 только в видео, токен продукта не менялся); перекрытие pop/whoosh на одной звуковой дорожке (pop → дорожка 5).
- Оставленные предупреждения: `text_below_floor` (125 элементов UI 9–13 px в обзорных кадрах 1:1 и 1.45× — интерфейс, не титры; крупные планы 2.0–2.2× дают 27–30 px); `line_unread` ×7 — строки UI, уходящие из кадра при смене экрана/движении камеры (не титры). Намеренные opt-out: панель `data-layout-allow-occlusion`, лента `data-layout-allow-overlap` (карточка едет поверх соседей), усечённые «…» строки чатов `data-layout-bleed`.
- Снимки до рендера: 0.5 / 3.0 / 5.0 / 7.0 / 8.9 / 9.9 / 10.9 / 12.5 / 16.0 / 17.6 с — найдены и исправлены три дефекта: правило скетча `.fl span` превращало вложенные span чипов фильтра в «чип в чипе» (счётчики ломались) → переопределение `.lb`/`.dg`; карточка после переезда упиралась в нижний край окна при обзоре 1.45× → кадр камеры опущен на 16 px (ry 40 → 56); курсор в покое лежал на тексте карточки → увезён левее колонки.
- `snapshot --review`: биты 0.3 / 0.6 / 4.2 / 8 / 8.275 / 10.8 / 12.9 / 16.85 / 17.925 с, шов ui→end (16.35–16.75: затемнение 70 % → чёрный кадр → знак из 1.6× — «dip cut», как в clip-01), телефонный лист 360 px — подписи читаются, текст UI — нет (ожидаемо).
- Рендеры: `renders/inbox-ru.mp4` (4,0 МБ), `renders/inbox-en.mp4` (3,9 МБ) — ffprobe 19.300 с каждый, h264 1920×1080 30 fps + AAC. Кадры 150 / 230 / 400 декодированы из ru-mp4 и просмотрены (`frames/`). EN проверен снимками 5.0 / 8.9 / 12.9 с: панель, лента, ответ, фильтры и подписи по-английски, ничего не вылезает.
- Звук измерен (`npx hyperframes audio`), не прослушан: ончеты 3.12 / 3.42 / 7.12 / 7.2 / 9.12 / 9.64 / 10.17 / 11.7 / 16.12 / 16.57 с совпадают с кликами (3.07, 7.07, 9.07, 16.07), «поп» ленты (3.3), раскрытия (7.15), «выполнено» (9.52), «вшух» переезда (10.1), счётчика (11.58), ударом знака (16.52); −16.5 LUFS integrated, true peak −8.9 dBTP, клиппинга нет. Музыки нет (решение владельца не принято); SFX — библиотека из clip-01 (`assets/sfx/CREDITS.md`).

## Творческие решения и что не строилось
- Счётчики: при «выполнено» коньячный «2 → 1» и серый «4 → 5» (выполненная карточка в скетче лежит в «к сведению» и входит в его счёт) — честнее, чем уменьшить только один.
- Фильтры «Все · Требует действия · К сведению» показаны в шапке и меняют счётчики, но курсор по ним не кликает — хронометраж 19 с отдан ответу в карточке.
- Сюжеты B («вечер: шесть событий прилетают») и C («до/после: четыре чата → одна лента») не строились — причины в STORY.md.

## Самый слабый кадр и что изменить при наличии времени
- Сцена 3 (3.3–6.2 с, обзор ленты 1.45×): текст карточек 19 px — зритель видит две группы и цвета, но читает только заголовки групп. Вариант: обзор 1.6× с обрезанным правым краем кнопок.
- Сцена 7 (11–15.6 с): 4,6 с на одном кадре «панель + шапка» после смены счётчиков — самое длинное статичное место. Вариант: укоротить на 0.8 с или добавить клик по чипу «Требует действия 1».
- Шов ui→end: 2 чёрных кадра между затемнением и знаком — читается как намеренный dip, но можно сократить затемнение до 50 %.

## Предупреждения, оставленные намеренно
- `text_below_floor` (UI продукта), `line_unread` (UI, уходящий из кадра) — см. выше.
- Плашка «alpha» в углу всего клипа — требование владельца.
