# Серия клипов Harnessy «как это работает» — общий бриф

Слово владельца 22.10.2026: клипы по функциям, 15–25 с, на русском и английском; смотреть будут НЕ ТОЛЬКО разработчики, но и простые пользователи;
особый акцент — Автопилот. Это альфа-версия продукта: плашка ALPHA в кадре, без слов «макет / не реализовано / так задумано».

## Семья (эталон — clip-01-sidebar)
- Формат: 1920×1080, 30 fps, 16:9, 18–25 с. Окно Harnessy сверху (скетч как живой DOM), полоса подписей 168 px снизу, плашка ALPHA справа внизу, финал — знак Harnessy · alpha.
- Один непрерывный дубль, камера ходит между общим и крупным планом, каждая смена кадра вызвана действием нарисованного курсора. Eases по references/motion.md, без линейных.
- Подписи — для обычного человека: простые слова, без жаргона (не «сессия», «роль-сид», «ревью-раунд»; да: «помощник», «команда», «решение», «вопрос»). Одна мысль на подпись, ≤ 7 слов, ключевое слово коньяком.
- Звук: UI-звуки на действиях (библиотека из clip-01 `assets/sfx`), музыки нет (пока владелец не решил).
- Два языка: все строки — переменные `data-var-text`, словарь ru/en в `tools/vars.mjs` (скопировать из clip-01), рендер `renders/Harnessy-<clip>-ru.mp4` и `renders/Harnessy-<clip>-en.mp4` (слово владельца 22.10: имена файлов с префиксом Harnessy-). EN-меню — как в clip-01 (New chat, Find…, Inbox, Pinned, Chats, Other projects, Documents, Artifacts, Project memory, Research, Plan · map, Path, Agent team, Dashboard, Profile, Connections, Settings, Journal, Help, Keys, Autopilot, Sign out, Appearance; Orchestrator / Executor / Reviewer / Worker / Researcher / Tester).
- Данные — из скетчей (Alpha-Test, Анна Ветрова, you@example.com, чаты примера). Имя и почта владельца в кадр не попадают.
- Источники визуала: скетчи `~/Harnessy/ui/sketches/disarto/` — 40-sidebar.html (+sidebar-v2.css), 41-team-canvas.html (+team-canvas.css/js), 00-design-code.html (секции sidebar-v2-spec, team-canvas-spec), 01-chat.html, 10-new-chat.html. Копировать DOM и CSS в композицию, не iframe.
- Проект каждого клипа: `~/Harnessy/ui/video/clip-NN-<имя>/` (`npx hyperframes init`), STORY.md (три сюжета, выбран один), SPEC.md, REVIEW.md, check без ошибок, preview, render обоих языков. Не коммитить.

## Клипы
02 autopilot — АКЦЕНТ. Сюжет для простого человека: вечер, в панели Входящие ждут 2 решения → профиль → «Автопилот» вкл «до утра» (подпись: «Уходите — помощник решит за вас») → ночь: карточки «оркестратор и проверяющий посоветовались → решение принято» появляются одна за другой (2–3), у каждой «почему» в одну строку → утро: Входящие «Автопилот решил 3 · к сведению», карточка раскрыта: что решено, почему, кнопка «Отменить» / «Хорошо» (подпись: «Утром видно каждое решение. Можно отменить»). Финал. Ключевые слова: доверие, прозрачность, отмена.
03 inbox — Входящие: панель → клик «Входящие 2·4» → лента «Требует действия» (решение с кнопками «Ответить», возврат проверяющего) и «К сведению» (ход завершён, подключение, лимит, обновление) → ответ прямо в карточке → карточка уходит вниз «выполнено». Подписи: «Всё, что ждёт вас, в одном месте», «Ответьте прямо здесь».
04 new-chat-to-project — Новый чат без проекта (вопрос «как заварить кофе в турке», ответ) → потом рабочий вопрос → «В проект ▾» → «Сделать проектом» → появляется проектная полоска (Чат · Документы · Артефакты · …) и чат в панели переезжает под проект. Подписи: «Просто спросите», «Выросло в дело — сделайте проектом».
05 rail-modes — Рейка-режимы (кадр A2 из 40): рейка всегда, клик по иконке открывает панель режима: Чаты → Входящие → Проект (карточка проекта и разделы) → Команда; панель можно отпустить (прячется). Подписи: «Узкая рейка — всё под рукой», «Нажмите — откроется нужное».
06 team-canvas — Полотно работы (кадр 01 из 41): вкладка «Команда агентов» → полотно: оркестратор с чатом наверху, карточки ролей, живая стрелка «Воркер 1 → Ревьюер · сдача», карточка «ждёт решения» подсвечена → «+ роль» → меню ролей. Подписи: «Видно, кто чем занят», «Стрелка — кто кому сейчас пишет».
07 team-constructor — Конструктор (кадр 02 из 41): «Открыть конструктор» → библиотека ролей слева → перетащить «Тестер» на холст → выбрать модель и права → связать с Ревьюером → «Сохранить» → «Применить к проекту». Подписи: «Соберите команду как схему», «Модель и права у каждой роли».
08 task-queue — Очередь задач (кадр 04 из 41): очередь с номерами → перетащить №14 на Воркера 2 → статус «у воркера 2» → задача уходит в его карточку. Подписи: «Задачи с номерами», «Перетащите — и она в работе».
09 discussion-mode — Режим общения (вариант (в) из 41): чат проекта → тумблер «Обсуждение» вкл → подпись «Помощник только обсуждает. Ничего не меняет» → пользователь пишет «а если переписать модуль?» → ответ-рассуждение без действий, чип «обсуждение» на ответе → выключил → «Теперь можно делать». Подписи: «Поговорить, не трогая проект».
