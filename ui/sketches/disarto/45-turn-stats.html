Harnessy · статистика хода под ответом

Под каждым ответом модели — иконка в строке действий; по клику карточка хода: модель и права, токены вход / выход / из кэша, стоимость по прайс-листу, время и вызовы инструментов. Данные — из записи хода движка (`context.last` сегодня даёт только последний ход места; для каждого ответа запись расхода нужно прикладывать к сообщению). Повод — карточка «Response statistics» в Devin; наша отличается деньгами, тик-полосой и честным состоянием «провайдер не сообщил».

Правила: иконка видна при наведении и у последнего ответа (как строка действий, дизайн-код «Сообщение»). Сумма у иконки — только если стоимость известна; иначе иконка без суммы. Раскрыта не больше одной карточки на чат. Числа — табличные цифры, тысячи через пробел. Неизвестное — слово «нет данных», не ноль.

Есть: расход последнего хода места (`context.last`: input, output, cacheRead) и прайс-лист владельца (TS-29) — из них уже считается строка под полем ввода.live
