## Инварианты всех вариантов (из концепции)
- В панели один вид объекта — чат (сессия). Роль — метка в строке (Оркестратор · Исполнитель · без метки для чата без роли; заголовка «БЕЗ РОЛИ» нет). Точка состояния: идёт ход · ждёт вас · ошибка · тихо.
- Главное действие сверху: Новый чат ⌘N, под ним Найти ⌘K.
- «Ждёт вас (N)» — строка-фильтр над чатами: чаты, где нужен владелец, + открытые решения (бывший «Сейчас»); клик — экран решений.
- Закреплённые — короткая группа (≤3 строки, «ещё» → поиск).
- Другие проекты — свёрнуты: одна строка «Другие проекты · 9» → список; проект меняется в шапке панели (проект ▾ с меню как сейчас).
- Разделы проекта (Документы · Артефакты · Память · Ресёрч) и План · карта · Путь — не в панели: вкладки шапки рабочей области (нарисовать ряд вкладок в шапке на экране).
- Низ: не больше двух блоков — лимиты одной строкой (Claude 64 % W · Codex 91 % W, клик → попап «Все лимиты» из скетча 27) и Профиль ▾ (Настройки ⌘, · Подключения · Журнал · Уйти из проекта · Облик · Клавиши · Выйти).
- Слова: «Ждёт вас» вместо «Сейчас»; «Уйти» только в меню профиля; пометки «демо» нет.
- Один явный активный элемент (текущий чат или экран).
- Рейка: пункты появляются только за живыми экранами; пока их мало — рейка короткая. Пункт без живого экрана не рисуется (не «макет» — его просто нет).

## Три варианта (каждый — кадр на странице; один и тот же экран «Новый чат» при 1440; плюс кадр 390 для выбранного по умолчанию)
A1 «Панель + рейка-сжатие». Широкая панель 260 px по инвариантам. Кнопка ⟨ сжимает её в рейку 56 px с теми же пунктами в иконках: Новый чат · Найти · Ждёт вас (бейдж N) · Чаты · Закреплённые · Проекты · низ: лимиты-кольцо · профиль. Рейка — то же дерево, просто узко. Подсказки по наведению.
A2 «Рейка-режимы + панель содержимого». Рейка 56 px постоянна: Новый чат · Найти · Чаты · Ждёт вас (N) · Проект (вкладки разделов: документы · артефакты · память · ресёрч · план · карта · путь — вместо вкладок в шапке) · Команда (роли со статусом, стая) · низ: лимиты-кольцо · профиль. Клик по пункту открывает панель 280 px с содержимым режима; «Чаты» — список как в A1; панель можно закрепить или отпустить (прячется по клику в рабочую область). Шапка рабочей области без вкладок (они в режиме «Проект»).
A3 «Только панель, разделы в шапке, рейка минимальная». Панель 240 px: проект ▾ · Новый чат · Найти · Ждёт вас · чаты (закреплённые сверху списка с булавкой, не отдельной группой) · Другие проекты · низ лимиты + профиль. Рейка (по ⟨) — только 4 иконки: Новый чат · Найти · Ждёт вас · Профиль; всё остальное через ⌘K. Шапка рабочей области: вкладки Чат · Документы · Артефакты · Память · Ресёрч · План · карта · Путь.

У каждого кадра: подпись «что ушло из панели и куда», плюсы/минусы в две строки, и мини-схема «ширина 1280: панель + рабочая область» (влезает ли).
