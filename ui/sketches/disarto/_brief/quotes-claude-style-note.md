# Цитаты в стиле Claude (слово владельца 22.10, кадр ref-claude-quotes.png)
Сейчас цитаты в Harnessy (TS-27) оформлены в стиле Markdown («> №1 …»). Нужно как у Claude: каждая цитата — КАРТОЧКА с левой полосой и обрезанным текстом (2–4 строки), подпись-чип «Ответ» (Reply) в углу; несколько цитат — сеткой карточек НАД полем ввода; при отправке сообщение показывает те же карточки сверху, клик по карточке прокручивает к исходному сообщению. Нумерация TS-27 сохраняется внутри карточки мелко (№3) для ссылок в тексте. Состояния: одна · несколько (сетка 3 в ряд) · длинная (обрезка «…») · удаление карточки (×) · в отправленном сообщении · на телефоне (в колонку).
