# Боковая панель Harnessy — критика и три концепции переработки

Дата: 22.10.2026. Поручение владельца: посмотреть панель глазами нового пользователя (после Claude Code Desktop, Codex Desktop, Antigravity, DeepSeek Desktop),
уйти от перегрузки, сохранить все возможности. Исходная точка — первый экран «Новый чат» прототипа.

## 1. Что в панели сейчас (15 блоков)
шапка: проект ▾ (меню смены) · ⟨ свёртка в рейку · Новый чат ⌘N · Найти ⌘K · РАБОТА: Сейчас · Чат (счётчик) · План · карта · ЗАКРЕПЛЁННЫЕ ·
ПРОЕКТЫ: текущий раскрыт → 4 раздела (Документы, Артефакты, Память, Ресёрч) → чаты по ролям (Оркестратор, Исполнитель…) → БЕЗ РОЛИ → «＋ чат без роли» ·
ещё N свёрнутых проектов «k ролей · git» · Журнал · низ: Уйти · Настройки · виджет ОСТАЛОСЬ (лимиты) · карточка Владелец ▾ (проект, облик, клавиши, настройки, выйти).
Плюс рейка (иконки) и палитра ⌘K (экраны, решения, действия). Под композером — «недавние» чаты.

## 2. Диагноз (сходятся моя опись и независимая критика Sonnet)
1. Четыре уровня в одной колонке: экран приложения / раздел проекта / роль / чат — с одинаковым отступом.
2. Дубли: проект в трёх местах (шапка панели, дерево, чип композера); роль — в строке чата и в чипе композера; новый чат — кнопка, ⌘N, «＋ чат без роли», ⌘K; закреплённые ≈ недавние ≈ дерево.
3. Слова, которых нет ни у одного из четырёх референсов: «Сейчас», «Уйти», «без роли», «Память проекта», пометка «демо».
4. Низ панели: четыре разнородных блока подряд (Уйти, Настройки, лимиты, владелец) на 150 px; лимиты занимают место постоянно, нужны раз в день.
5. Раскрытый проект съедает треть высоты; десятый проект выглядит так же, как первый; нет сигнала «где я» кроме подсветки «Новый чат».

## 3. Частота использования (разметка)
- Ежеминутно: новый чат, поиск, чаты текущего проекта с признаком «идёт ход / ждёт вас», переход между чатами.
- Раз в день: решения и очередь («Сейчас»), план/карта/путь, лимиты «есть ли запас», смена проекта, закреплённые.
- Раз в неделю, но под рукой: документы, артефакты, память, ресёрч, журнал, подключения, настройки, остальные проекты.
- Почти никогда: «Уйти», свёртка в рейку, отдельная группа «без роли».

## 4. Закономерности референсов (Claude Code, Codex, Antigravity; DeepSeek не подтверждён)
Центр панели — один список сессий, сгруппированный по проекту (Claude: фильтры + группировка; Codex: Pinned → Projects → Recents; Antigravity: Inbox со статусами Idle/Running/Blocked + Workspaces).
Главное действие сверху. Работа внутри сессии (терминал, diff, режимы, вложения, модель) — в области сессии и композере, не в панели. Рутина (архив, удаление, квоты) — за кликом;
спрятанные квоты — главная жалоба на Antigravity 2.0. Масштаб: сузить список до живой работы (авто-архив, закреплённые, поиск).

## 5. Три концепции

### А · «Список сессий» (как Codex/Claude Code): панель = проекты и чаты, всё остальное — в рабочую область
Панель сверху вниз: [проект ▾ · ⟨] · Новый чат ⌘N · Найти ⌘K · **Ждёт вас (N)** (строка-фильтр: чаты, где нужен владелец, + открытые решения) · Закреплённые ·
Чаты текущего проекта (одной группой; роль — метка в строке, «без роли» без заголовка; «идёт ход»/«ждёт» — точка) · Другие проекты (свёрнуто, по клику — список) ·
низ: Лимиты одной строкой (Claude 64 % W · Codex 91 % W, клик — попап «Все лимиты») · Профиль ▾ (Настройки ⌘, · Подключения · Журнал · Уйти · Облик · Клавиши).
Куда ушло: Документы/Артефакты/Память/Ресёрч → вкладки шапки рабочей области проекта (как «План · карта · Путь»); «Сейчас» → фильтр «Ждёт вас» + экран по клику; Журнал/Уйти/Настройки → меню профиля.
+ Максимально знакомо человеку из Codex/Claude Code; панель короче в 2–2,5 раза; один объект в колонке — чат.
− Риски: (1) владелец 08.10 сказал «Сейчас · Чат · План — не трогать»: концепция убирает группу РАБОТА — нужно его слово; (2) разделы проекта становятся на один клик дальше;
(3) «Ждёт вас» как фильтр списка требует живого статуса чатов от движка (есть: busy/waiting в live.js).

### Б · «Две зоны: проект и команда»: панель = карточка проекта + роли, чаты — внутри ролей
Панель: [проект ▾ · ⟨] · Новый чат · Найти · **Карточка проекта** (имя · git · N ролей · «ждёт вас N» · бюджет; клик — паспорт проекта: документы, артефакты, память, ресёрч, план/карта/путь, журнал) ·
**Команда** (роли как в «Стае»: Оркестратор · Исполнитель · Ревьюер — у каждой статус и последний чат; клик по роли — её чаты; «чат без роли» — одна строка внизу команды) ·
Закреплённые · низ: Лимиты строкой · Профиль ▾ (настройки, подключения, уйти).
Куда ушло: все разделы проекта — в паспорт проекта (одна карточка-поверх по принципу «обзор → карточка»); другие проекты — только через меню проекта ▾; «Сейчас» — счётчик на карточке проекта + экран по клику.
+ Подчёркивает то, чего нет у референсов: команда ролей — главная фича Harnessy; панель = «где я и кто работает».
− Риски: (1) непривычно новичку из Codex — чат на два клика (роль → чат); (2) при 8 ролях команда снова длинная; (3) паспорт проекта — новый экран, которого нет в скетчах (нужен дизайн-код).

### В · «Рейка + выдвижная панель» (как Antigravity Agent Manager / VS Code): всегда видна узкая рейка, широкая панель — по режиму
Рейка 56 px, сверху вниз: Новый чат · Поиск · **Чаты** · **Ждёт вас (бейдж)** · **Проект** (документы, артефакты, память, ресёрч, план/карта/путь) · **Команда** (роли, стая, датчики) · низ: Лимиты (кольцо-индикатор, клик — попап) · Профиль.
Клик по иконке рейки открывает панель 280 px с содержимым этого режима (как «Explorer/Search/Git» в VS Code); панель можно закрепить или прятать. Режим «Чаты» — концепция А в чистом виде.
Куда ушло: всё, что не чаты, — в режимы рейки; «Журнал», «Уйти», «Настройки» — в профиль.
+ Самая короткая первая панель (только чаты), все фичи на один клик, рейка уже есть в прототипе; хорошо масштабируется на новые разделы (Путь, Датчики, Стая).
− Риски: (1) две колонки слева съедают ширину на ноутбуке 1280; (2) режимы рейки — новое поведение, нужно обучить (подсказки); (3) иконки без подписей — та же жалоба, что к рейке сейчас.

## 6. Что общее во всех трёх (предлагаю принять независимо от выбора)
- Переименовать: «Сейчас» → «Ждёт вас»; «Уйти» → «Уйти из проекта» в меню профиля или убрать из панели; «без роли» → просто чат без заголовка-группы; снять пометку «демо» с «План · карта».
- Один факт — одно место: проект меняется только в шапке панели; чип проекта из композера убрать (роль и модель остаются в композере).
- Лимиты — строка, не блок; пустой виджет не рисуется (решение 15.10: 100 % серым, если нет данных — оставить, но в одну строку).
- Активный элемент один и явный: текущий чат/экран подсвечен, плюс точка состояния у чатов (идёт · ждёт вас · ошибка).
- Низ панели: не больше двух постоянных элементов (лимиты + профиль).

## 7. Рекомендация
А как базу (знакомо, дёшево, панель короче вдвое) + элементы В (рейка как сжатый режим А с теми же пунктами). Б — если владелец хочет, чтобы «команда ролей» была лицом продукта; тогда делать её
паспорт проекта по принципу карточки поверх. Решение «Сейчас · Чат · План не трогать» (08.10) нужно пересмотреть словом владельца — все три концепции его меняют.
