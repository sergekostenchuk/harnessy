## Что нужно (слова владельца)
- Основа — КАРТА. Карточки = блоки/события, у каждой есть ВХОД → ДЕЙСТВИЕ → ВЫХОД, есть соседи и взаимосвязи ПО СУТИ.
- Карта РИСУЕТСЯ ПО ХОДУ прохода OM: дискавери → замысел → блоки и договоры → операции → работы → план задач, а затем РЕАЛИЗАЦИЯ плана задач на той же карте.
- Взаимосвязанные карточки блоков РАСКРЫВАЮТСЯ в карточки подблоков с графами взаимосвязей — с картой РАБОТАЮТ.
- Стиль n8n (граф узлов со стрелками), НО визуально как скетч 02 (ui/sketches/disarto/02-plan.html, то, что на скриншоте владельца: тёмные карточки, плашка статуса, заголовок, сегментный прогресс, мелкие чипы, тонкие кривые связи, панель «Текущий этап» справа вверху, полоса «запуски сегодня» внизу). Для ЧЕЛОВЕКА, а не для машины.
- Связи — интерактивные стрелки. Клик по блоку/подблоку: его связи (входящие и исходящие) выделяются (акцент #c27a34), остальные карточки и стрелки приглушаются; соседи подсвечены. Клик в пустоту — сброс.
- Стадии видны всегда. Таймлайн внизу.
