Путь проекта как карта, по которой владелец ходит: узел «Вход» (не стадия) и восемь стадий из кода — карточки «вход → дело → выход»; стадия раскрывается в рамку с внутренними узлами (вход слева → выход справа, длинная цепочка — полосами змейкой), стрелки с подписями артефактов; клик по узлу подсвечивает его связи и открывает карточку поверх с содержимым экранов 28–38. Узлы с точкой владельца — бейдж владелец. Состав узлов и связей — из карты прохода OMG; плашки честности — по её статусам, есть означает «есть в движке OMG».
