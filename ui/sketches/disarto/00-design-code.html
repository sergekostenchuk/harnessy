правила

01

Один экран — одно дело. Обзор: числа и строки, без подробностей.

02

Детали — раскрытой карточкой поверх экрана, из того объекта, по которому кликнули. Не новой страницей.

03

Соседнее — вкладками, потоки — шагами внутри карточки.

04

Акцент один — коньячный. Он значит «ждёт вас» или «главное действие»; зелёный и бордо — только состояния.

05

Золото — только знак и имя бренда. В тексте и кнопках его нет.
