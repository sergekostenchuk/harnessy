правила

01

Один экран — одно дело. Обзор: числа и строки, без подробностей.

02

Детали — раскрытой карточкой поверх экрана, из того объекта, по которому кликнули. Не новой страницей.

03

Соседнее — вкладками, потоки — шагами внутри карточки.

04

Акцент один — коньячный. Он значит «ждёт вас» или «главное действие»; зелёный и бордо — только состояния.

05

Золото — только знак и имя бренда. В тексте и кнопках его нет.

Как формируется проект · элементы карты

Карта показывает, как любой проект формируется по восьми стадиям, и растёт вместе с ними: идея → для кого и требования → схема блоков → поведение и фичи → подблоки, пробелы и работы → задачи → исполнение. Это иерархия, по которой можно походить: блок → подблоки → работы → задачи. Элементы ниже — ровно те, из которых собран скетч 26; визуальный язык — план-карта 02 (карточки с плашкой, сегментный прогресс, чипы, плавные связи, панель «Текущий этап», полоса внизу). Прежние элементы v2 (карта движка, слой «План» с привязкой задач к узлам базы, таймлайн по событиям, легенда запусков) удалены.

так говорим

проект · стадия · блок · подблок · работа · задача · вход → действие → выход · артефакт на связи · успех / отказ · пробел: открыт / закрыт (код · модель · вы — выбор из вариантов) · ответ движка на работу: принят / возвращён · задача: предмет · потребитель · область записи · проверка · вернулась в план · переиздана · раскрыть · крошки. Стадии — по-русски, кодовое имя мелко: «Операционная карта · operation-map».

так не говорим

идентификаторы, хэши, английские внутренние слова на экранах; дашборды состояния; данные конкретного проекта вместо смысла; подшаги прохода (R0–R3, G5, M8) — только мелко в панели стадий, если нужны. Правила движка не переписываются текстом на экран — только то, что человек видит или делает.

три правила карты
01

Одна карта растёт. Каждая стадия добавляет слой на ту же карту; таймлайн внизу — по восьми стадиям, ползунок показывает карту на выбранной стадии.

02

Карточка = вход → действие → выход. Клик — связи и соседи коньячные, остальное приглушено, справа панель «вход → действие → выход, соседи, пробелы». «Раскрыть» или двойной клик — внутрь: подблоки → работы → задачи; крошки — назад.

03

Отрисовка из данных. Раскладка — слойка по связям, число блоков, подблоков, работ и задач нигде не зашито; та же отрисовка работает на любом проекте.
