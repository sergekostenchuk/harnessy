# Harnessy-alpha для тестеров

1. Откройте `Harnessy-alpha-…-arm64.dmg`, перетащите приложение в `Applications` и запустите его через Finder. Сборка пока не подписана: macOS может попросить подтвердить запуск в «Системные настройки → Конфиденциальность и безопасность».
2. Harnessy уже содержит свой движок. Отдельный Node.js не нужен. Программы моделей ставятся отдельно: Claude Code, Codex, Gemini, Qwen и другие — вкладка «Подключения» покажет, что найдено и как войти.
3. Настройки остаются в `~/.harness-*.json`, журнал и служебные файлы — в `~/.harnessy/`, данные проектов — в выбранных папках. API-ключи хранятся в связке ключей macOS и не входят в приложение.
4. В замечании укажите версию из «Настройки → О программе», шаги и видимый текст ошибки. Приложите `~/.harnessy/server-desktop.log`; журнал действий текущего проекта можно выгрузить из экрана «Журнал».

Это внутренняя alpha: интерфейс и форматы ещё могут меняться.
