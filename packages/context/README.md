# @harnessy/context

Чистые функции текстов и карточки контекста, Node ≥22, ESM, TypeScript strict. Внешних runtime-зависимостей нет; пакет не читает файлы и не запускает процессы.

`memorySections(text)` возвращает ReadonlyMap с порядком Python, включая числовые заголовки; удаляет заглушки в скобках и прочерки. `onboarding(seat, how, deps)` получает память, инструкции, сводку политики, команду, журнал, подписи режимов и фиксированное `now` как данные. `roleNote(seat, deps)` собирает права/ветку/worktree и инструкции. `handoffPrompt` и `transcriptText` готовят передачу контекста.

`digest(viewer, others, canObserve)` возвращает новый `{text, nextSeen}` и не потребляет seen. Наблюдение проверяется до доступа к ленте. Runtime применяет nextSeen только после долговечного результата. Бюджет 6000 — сумма блоков до добавления многоточия; заголовок и разделители не считаются, как в Python. Пустые реплики результата исключены из digest/transcriptText по TS-04a:46.

`estTokens` и `contextWindow` сохраняют оценку и таблицу Python; округление использует точное IEEE-754 значение и ties-to-even. `contextCard(pane, {instructionText, roleNote, chat})` считает общий расход измеренным только при наличии всех трёх счётчиков. Частичные счётчики сохраняются в `last` и, для счётчиков входа и кэша, в `cache`; отсутствующие значения — `null`. Иначе `used` является оценкой, а части system нет. Остаток system и свободное место по таблице — оценки. Неизвестная модель возвращает `window`, `pct` и токены части `free` как `null`. Карточка не обрезает входную историю; на выходе history ограничена последними 60 записями.

`src/fixtures/python.json` — эталоны из AST функций исторического Python-модуля app (тег mvp-python) без импорта сервера/провайдеров и без вызовов моделей, с фиксированными входами и временем. Единственное изменение образца в эталонах — согласованный пропуск пустых реплик в сводке и передаче. Тесты включают порядок/безопасность ключей памяти, Unicode, обрезку, обе концовки вводной, политику наблюдения и карточку до/после измерения.
