# TS-40 — Статистика хода под каждым ответом (карточка хода)

Статус: 26.10.2026, слово владельца «поставь после автопилота» — выполняется после TS-38 (38.1–38.5). Скетч `ui/sketches/disarto/45-turn-stats.html` (кадр 1, вариант А), дизайн-код `00-design-code.html` секция `turn-stats-spec`.
Повод — карточка «Response statistics» в Devin; наша отличается стоимостью по прайс-листу, тик-полосой долей и честным состоянием «провайдер не сообщил».

## Смысл
Под каждым ответом модели — иконка в строке действий сообщения с суммой хода (если стоимость известна); по клику карточка: номер хода, модель, права, вызовы инструментов, длительность; вход / из кэша (доля %) / выход / стоимость; тик-полоса; контекст после хода; «Скопировать id хода», «Открыть в журнале».
Строка под полем ввода остаётся итогом по месту и проекту (сегодня, лимит, контекст) — карточки её не дублируют, сумма карточек за день = число внизу.
