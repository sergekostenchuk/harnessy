# TS-34 — Первый запуск без тупиков

Статус: 15.10.2026, слово владельца по alpha: «непонятно, почему нужно сразу назначать оркестратора; выход из этого меню — не через отказ от оркестратора, а через подключение моделей, которое не работает». Оркестратор: claude-orch. Исполнитель — воркер 1 после TS-32.

## Принципы (слово владельца)
- Оркестратор — не ворота. Назначить его можно позже из чата; на первом запуске он не требуется.
- Выход из любого шага не зависит от того, заработало ли подключение.
- «Просто чат» — настоящая кнопка, всегда рабочая.

| № | Что видит человек | Исход «готово» |
|---|---|---|
| 1 | **Шаг «что у вас есть»:** список найденных программ и карточки «не нашли» (TS-33) с «Установить» / «Указать путь»; подключить можно, обязательным не является. Внизу — две равноправные кнопки: «Подключить выбранное» и **«Просто чат»**. | тест: ни одной подключённой программы → «Просто чат» ведёт в пустой чат |
| 2 | **Пустой чат без моделей:** одна карточка «Подключите модель, когда захотите» → ведёт в «Подключения»; поле ввода доступно, при отправке без модели — словами «Сначала выберите модель» (TS-08), не ошибка. | ничего не блокируется; карточку можно закрыть |
| 3 | **Оркестратор — предложение, не требование:** после первого ответа модели (или по кнопке «Назначить роль») — карточка «Назначить оркестратора этому разговору?» с «Назначить» / «Не сейчас»; «Не сейчас» запоминается на чат. Экран «Назначить оркестратора» из потока первого запуска убирается. | тест: отказ не мешает дальнейшей работе; назначить можно позже из того же чата |
| 4 | **Нет тупиков:** на каждом экране потока — «Назад» и «Просто чат» видны и работают; состояние «подключение не удалось» показывает причину словами и те же две кнопки. | проход по всем экранам первого запуска с отказом подключения на каждом шаге — везде есть выход |
| 5 | Экран «alpha» (TS-30) и дисклеймер — до шага 1, как сейчас. | — |

Правила: сначала скетч/дизайн-код (кнопки шага 1, карточка «подключите модель», карточка-предложение оркестратора), потом окно; снимки 1440 с живого окна на своём порту и с HARNESSY_TEST_WINDOW=hidden (после TS-33); старые тесты первого запуска (TS-19) обновить явно с перечнем. Полный `npm test`.
