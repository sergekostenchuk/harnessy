## Принцип (как у Claude Code и Codex сегодня)
Харнесс не хранит входы подписок и не заводит аккаунты: он запускает программу провайдера, видит её вход, даёт модели и ходы через её безголовый режим, инструменты Harnessy — через MCP-сервер pane-mcp, который подключается в конфиг этой программы на время хода. Ключи API — отдельно (SEC1).
