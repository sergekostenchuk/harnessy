# TS-09b6 — Выбор роли из «Предложено в разговоре» = открыть её чат с контекстом проекта и составом команды

Статус: слово владельца 12.10.2026 01:10 (снимок меню «Предложено в разговоре» в «Юристы 4114»). Исполнитель — codex-worker после круга 2 TS-19 (TS-18 уходит воркеру 2 после TS-17). Код сразу по строкам, одно ревью. Оркестратор: claude-orch.

| № | Что | Решение |
|---|-----|---------|
| 250 | клик по роли | «Создать эту роль» (или клик по строке) → место создаётся дверью владельца TS-09b5 и окно СРАЗУ переходит в чат этой роли (привязка к новому месту, как после повышения TS-09b2), с карточкой хода операции TS-09b4 на время создания; повторный клик по уже созданной роли — просто переход в её чат (в меню такая строка подписана «чат открыт») |
| 251 | что получает роль при открытии | до первого платного хода в чате роли видна карточка «Что знает эта роль»: цель и память проекта (MEMORY.md), прикреплённые документы, её вводная из предложения, и **состав команды**: все строки предложения с состоянием — «создана · чат открыт» / «предложена · чата ещё нет» / «создана владельцем как <класс>», с классом, моделью и задачей; оркестратор — отдельной строкой. Тот же текст идёт первым ходом модели (вводная TS-09b3 расширяется составом с состояниями), без лишнего вызова модели |
| 252 | роль узнаёт об изменениях | когда позже создаётся/меняется другая роль, в следующий ход каждой роли добавляется короткая строка «изменения в команде: …» (из состояния, не из текста); карточка «Что знает эта роль» обновляется по SSE |
| 253 | меню и карточка состава | в «Предложено в разговоре» и в карточке «Состав команды» у каждой строки состояние как в 251; «Подтвердить состав» создаёт всех оставшихся и предлагает перейти в первый созданный чат; никаких дублей при повторных кликах (ключ TS-09b5) |
| 254 | тесты | DOM+HTTP: клик → место создано → привязка переключилась → карточка с составом и состояниями; повторный клик → переход без второго места; состав в первом ходе модели (дублёр) содержит состояния; создание второй роли → «изменения в команде» в следующем ходе первой; поздний ответ после смены проекта не переключает привязку; чужие предложения/проекты не попадают |

Пути: `ui/deploy/{cx.js,live.js,proto.css}`, `packages/runtime/src/{proposals.ts,chats.ts,roles.ts}`, `packages/context/src/*` (вводная с составом), `packages/api/src/*` (тесты), `ui/sketches/disarto/00-design-code.html` (карточка «Что знает эта роль»).
