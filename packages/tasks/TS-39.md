# TS-39 — Очередь задач и конструктор команды: из макета в движок

Статус: 26.10.2026 — слово владельца 23.10 «сначала это реализуй» (после TS-38; TS-38 закрыта 26.10). Нарезка — ревьюеру на сверку до выдачи. Мерило — скетч 41 (полотно работы, очередь с номерами, конструктор), дизайн-код `team-canvas-spec`, решения владельца 22.10 (`_brief/41-team-canvas-brief.md`). Сейчас в окне (TS-36D, `ui/deploy/team-live.js`): полотно и карточки ролей — живые; очередь задач — макет из `TC.QUEUE0`; в конструкторе живые только модель и права места; «связи/порты», «своя роль», «сохранить инструкцию» — макет.

## Факты движка (26.10)
- Журнал проекта: записи `kind:'task'` (владелец → место; поручения `promotion:<op>:task`), ответы `answer/ack/review-request/verdict` через `reply_to`; `journal.pendingFor(seat)` — недоставленные записи места; `/api/swarm` отдаёт по месту `pending`, `queue`, `waiting`, `turn.records`. Нумерации задач и отдельного хранилища очереди нет.
- Состав: `/api/seats/proposals`, `/api/seats/confirm`, `/api/seats/owner` (создание места из предложения, класс прав), `/api/assign` (чат без роли → роль из каталога), `/api/panes/:id` (модель, права). Инструкция роли читается `/api/project/file`, записи нет.

## 39.1 — Очередь задач из журнала (потребитель: блок «Очередь» на полотне работы и экран «Команда агентов · очередь»)
| № | Что видит человек | Исход «готово» |
|---|---|---|
| 1 | Движок: `GET /api/tasks` — задачи проекта, выведенные из журнала без нового хранилища: каждая запись `kind:'task'` от владельца или оркестратора = задача; номер = порядковый среди задач проекта (устойчив, по seq); состояние по фактам: «в очереди» (есть в `pendingFor` адресата), «в работе» (в `turn.records` активного хода адресата или доставлена и нет ответа), «на ревью» (есть `review-request` в ответах по `reply_to`), «готово» (есть `answer`/`ack` с исходом от адресата или `verdict ≥ порога`). Поля: `n, seq, text (первая строка), from, to, state, thread, ts, replies`. | Тесты на четыре состояния из образца журнала текущего кода; отозванные записи автопилота (38.4) не показываются. |
| 2 | Движок: `POST /api/tasks/:seq/assign {to, project, revision}` — переадресация задачи из очереди другому месту = новая запись `task` от владельца с `reply_to` исходной и пометкой переадресации; исходная помечается отменённой для прежнего адресата (как отзыв 38.4, без удаления). Только owner; задача «в работе» не переадресуется (typed-отказ `task_active`). | Тесты: переадресация из очереди; отказ для активной; повтор безопасен. |
| 3 | Окно: блок очереди на полотне и экран очереди — из `/api/tasks`, фильтры по состоянию живые, перетаскивание строки на карточку роли → `assign`; пометки «макет» сняты; пустая очередь — честное «задач нет». | Снимки 1440/390 из собранного proto; тест live-ui на разбор и отсутствие `QUEUE0`. |

## 39.2 — Конструктор: инструкция и своя роль (потребитель: экран «Конструктор команды»)
| № | Что видит человек | Исход «готово» |
|---|---|---|
| 1 | Движок: `POST /api/project/file` запись текста инструкции роли — только owner, только путь `instructionPath` существующего места внутри проекта (canonicalPath, без выхода за проект), атомарная запись с проверкой `revision`/хэша прочитанного (check-then-act закрыт), запись в журнал `note` «инструкция обновлена». | Тесты: чужой путь → отказ; устаревший хэш → `file_changed`; успешная запись видна следующим ходом. |
| 2 | Окно: textarea инструкции редактируемая, кнопка «Сохранить инструкцию», отказы показаны; «Своя роль» ведёт на существующий путь: новый чат без роли → назначить роль (`/api/assign`) с именем и вводной — без новой двери движка; «связи/порты» остаются оргсхемой из фактов (оркестратор → роли), пометка «макет» с полотна конструктора снимается только с того, что стало живым. | Снимки; тест на отсутствие пометки «макет» у инструкции и наличие у связей. |

Правила: ничего сверх скетча 41 и дизайн-кода; формы записей — свои, на месте; полный `npm test` через test_slot; сдача — SHA, снимки, таблица сценариев. 39.1 и 39.2 — разные ветки, можно параллельно (39.1 — воркер 1 после TS-42, 39.2 — воркер 2 после TS-40).
