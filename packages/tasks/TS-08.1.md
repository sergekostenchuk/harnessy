# TS-08.1 — Снимок модели запуска переживает служебные заметки

Статус: **ВЛИТА** в main 11.10.2026 — сдача 4b0ff937, ревью №287 9/10, ворота 613/613. Оркестратор: claude-orch.

## Факт (№275, пробы ревьюера /tmp/harnessy-ts08-r2-independent.ts и /tmp/harnessy-ts08-r2-carry.ts)
`ui/deploy/live.js:141` вызывает `finish()` на любой `note`; в ходе с перенесённым контекстом движок выдаёт `state(busy:true, model:w1) → note → delta`: снимок w1 создаётся, заметка его удаляет, `live.js:131` создаёт ответ заново без модели — подпись «модель не сохранена» до `done` (итоговая модель из `done` сохраняется верно).

## Исход (строка 129)
| № | Ситуация | Исход |
|---|---|---|
| 129 | нетерминальная `note` во время активного запуска | снимок активного запуска (модель, место, поколение) сохраняется; `finish()` вызывается только на терминальные `done`/`error` провайдера (как в TS-07/77 для `unserializable`); регрессия: `state(busy) → note (carry/digest) → delta → done` — подпись модели w1 с первой delta и до конца, одна реплика. |

## Пути
`ui/deploy/live.js`, `packages/api/src/live-ui.test.ts`. Ветка от нового main.
