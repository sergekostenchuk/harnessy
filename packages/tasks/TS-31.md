| № | Что | Исход «готово» |
|---|---|---|
| 1 | **Подпись и нотаризация** в `electron-builder`: Developer ID Application, hardened runtime, entitlements (сеть, дочерние процессы, Seatbelt-песочница агентов), нотаризация через App Store Connect API key; секреты ТОЛЬКО из переменных окружения CI/локальной среды владельца (`CSC_LINK`, `CSC_KEY_PASSWORD`, `APPLE_API_KEY`, `APPLE_API_KEY_ID`, `APPLE_API_ISSUER`) — в репозитории и в сдаче их нет | подписанный и нотаризованный `.dmg` открывается на чистой машине без предупреждений Gatekeeper; `spctl --assess` и `stapler validate` зелёные |
| 2 | **Автообновления:** `electron-updater`, провайдер GitHub, репозиторий релизов (публичный, только бинарники и список изменений); проверка при запуске и раз в 6 ч; тихая загрузка; плашка «Обновление готово — перезапустить» в окне (элемент сначала в дизайн-коде); перед заменой — корректная остановка движка :3777 и перезапуск нового (TS-30 п.1); откат — предыдущий релиз в репозитории | тест: версия N → N+1 обновляется без перезагрузки системы; движок после обновления отвечает новой версией |
| 3 | **Каналы:** `beta` (тестеры) и `latest`; переключатель в «Настройках» (элемент в дизайн-коде) | тестер на `beta` получает пререлизы, на `latest` — нет |
| 4 | **CI:** GitHub Actions в приватном репозитории по тегу `v*`: build → sign → notarize → publish в репозиторий релизов (токен с правом только на него, в секретах Actions); `CHANGELOG` из описания тега | тег → релиз появляется автоматически; черновик релиза без тега не публикуется |
