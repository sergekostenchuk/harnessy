## Факт (№358, проба ревьюера /tmp/harnessy-ts09a-history-return.ts)
`live.js:201`: `pagehide` навсегда ставит `PS.alive=false`, обработчика `pageshow` нет; при возврате через bfcache скрипт заново не выполняется — «Обновить» и «Отправить оркестратору» молча прекращаются, без запросов и объяснения.

## Исход (строка 152)
| № | Ситуация | Исход |
|---|---|---|
| 152 | возврат страницы раздела из кэша истории (`pageshow` с `persisted:true`) | жизненный цикл страницы восстанавливается: `PS.alive=true`, новое поколение страницы, повторное подтверждение проекта (`/api/status`) и повторное чтение раздела; ответы, начатые до ухода, недействительны; действия «Обновить» и «Отправить оркестратору» работают. Регрессия через дубль DOM: загрузка → `pagehide` → `pageshow(persisted)` → оба действия шлют запросы; общий механизм — для всех страниц прототипа, где есть `pagehide` (цикл по `PROTO_PAGES`). |
