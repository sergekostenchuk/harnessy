# TS-05 — HTTP/SSE-сервер и запуск: пакет `packages/api`

Статус: черновик (на сверку — после TS-04). Оркестратор: claude-orch.
Образец: `core/app/server.py` — все обработчики маршрутов (список ниже), `events` (SSE), `no_cache_static` (1760–1775), `main()` (1780–1792:
последний проект, `DEFAULT_DIR`, `PROJECTS_ROOT_DEFAULT`, `SITE_DIR`, `PORT`, печать адресов), `status` (596–620), `claude_auth`, каталог моделей
(`models` — таблица Claude + `codex.models()`), `api_send/api_ask/api_merge/pane_transcript/api_assign_role` (HTTP для моста Codex), `journal_read`,
`sessions`/`session_one`, `dir_check`, `index`. Окно: `ui/deploy/out/site/sketches/**` (отдаётся как есть), Electron `ui/desktop` (не меняется).
Тесты-источники: `test_events.py`, `test_connections.py:80` (правила маршрута подключений), `test_pins.py`, `test_settings.py`, `test_handoff.py` (формы ответов),
`test_project_init.py` (формы `project_create`/`assign`), `test_halt.py`.

## Цель
Тот же контракт, что у Python-ядра, **байт в байт по формам JSON** (имена полей, статусы, тексты ошибок), чтобы `ui/` и Electron не заметили смены ядра.
`api` — тонкий слой: разбор запроса → вызов `runtime`/`projects`/`journal` → ответ. Логики в нём нет.

| Маршрут | Обработчик Python | Пакет-исполнитель |
|---|---|---|
| `GET /` | `index` | api (переадресация на окно) |
| `GET /api/status` | `status` | runtime (`project, defaultDir, models, modes, kinds, ownerKinds, lineErrors, policy, team, repo, panes[+pending], roleCatalog[available,reason], activeChats, hasOrchestrator, halted, threads, auth, journal, noProject, projectsRoot`) |
| `GET /api/dir` | `dir_check` | projects |
| `POST /api/project`, `/api/project/create`, `GET /api/projects` | `project_set`, `project_create`, `api_projects` | runtime.openProject / projects |
| `POST /api/panes/{id}` | `pane_set` | runtime (`Registry.update`, kick при очереди) |
| `GET /api/events/{id}` | `events` | api (SSE: `all` и одно окно; `: ok`, `: ka` каждые 15 с, открытые карточки при подключении, очередь 4000) |
| `POST /api/chat`, `/api/steer`, `/api/approve`, `/api/interrupt`, `/api/halt` | `chat`, `steer`, `approve`, `interrupt`, `api_halt` | runtime |
| `GET /api/sessions`, `/api/sessions/{id}` | `sessions`, `session_one` | providers через runtime |
| `POST /api/send`, `/api/ask`, `/api/merge`, `/api/assign_role`, `GET /api/pane_transcript` | мост Codex | runtime; **проверка `X-Pane-Token`**: токен зарегистрирован у места `from` И у места идёт ход, иначе 403 `{"ok":false,"code":"token_invalid"}`; `from` только из тела/запроса, сверяется с местом токена |
| `GET /api/journal` | `journal_read` | journal |
| `POST /api/room`, `/api/room/move`, `/api/assign`, `/api/seats`, `/api/onboard`, `/api/handoff` | комната, роли, передача | runtime |
| `GET/POST /api/pins`, `/api/settings`, `GET /api/connections`, `POST /api/connections/route`, `/check` | закреплённые, настройки, подключения | projects |
| `GET /api/context/{id}` | `api_context` | context через runtime |
| `GET /api/chats`, `/api/chats/{id}`, `POST /api/chats/new`, `/api/chats/open` | чаты | runtime |
| `/sketches/**` | статика | api: `Cache-Control: no-cache`, без индекса; `HARNESSY_SITE` или `ui/deploy/out/site/sketches` |

## Запуск
`packages/api/bin/harnessy.ts` (или `run.sh` в корне): порт `PORT` (3777), хост `127.0.0.1`; проекты: последний из `~/.harness-last-project`, иначе
`DEFAULT_DIR`; создать `DEFAULT_DIR` и `PROJECTS_ROOT_DEFAULT`; печать «[harness] линия: … · мест N · политика vK · записей M», «вход Claude по подписке: да/нет»,
адрес окна. Каталог моделей Claude — таблица ядра по списку Claude Code (скриншот владельца 09.10): `claude-opus-5-5` «Opus 5.5», `claude-fable-5-1` «Fable 5.1»,
`claude-sonnet-5-5` «Sonnet 5.5», `claude-haiku-5-5` «Haiku 5.5», плюс `claude-haiku-4-5-20251001` «Haiku 4.5» для уже существующих мест; Codex — из `provider.models()` с запасным списком при ошибке. Electron `ui/desktop/run.sh` и `main.js` не меняются
(ждут `/api/status` на 3777 и запускают `core/run.sh` — на переходе `run.sh` корня должен поднимать новое ядро).

## Таблица исходов
| № | Ситуация | Исход |
|---|---|---|
| 1 | любой маршрут из таблицы | тот же статус и та же форма JSON, что у Python (golden-тесты по `core/tests`: формы `project_create`, `assign`, `handoff`, `pins`, `settings`, `connections/route`, `halt`) |
| 2 | мост Codex без токена / с чужим / вне хода | 403 `token_invalid`; с верным — как Python |
| 3 | SSE `all` | события с `pane`, карточки при подключении, keep-alive, переполнение отписывает (`test_events`) |
| 4 | статика | `no-cache` на `/sketches`, 404 без индекса, версии `?v=` окна не трогаются |
| 5 | старт | последний проект или `DEFAULT_DIR`; папки нет → `DEFAULT_DIR`; `HARNESS_NO_LAST` в тестах |
| 6 | неизвестный маршрут / не-JSON тело | 404 / 400 с текстом как aiohttp (`{"error": …}`) — проверить формы на двух примерах |
