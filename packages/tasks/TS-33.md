# TS-33 — Программы находятся из приложения; «Подключить» понятно человеку

Статус: 15.10.2026, находка владельца на alpha (Codex и Devin «не подключены, как подключить — непонятно»). Оркестратор: claude-orch.

## Факт
Alpha из Finder получает системный PATH `/usr/bin:/bin:/usr/sbin:/sbin`; движок внутри .app копирует `process.env` провайдерам (cli/provider.ts:49) → `codex`, `devin`, `claude` из `~/.local/bin` не найдены, каталог отдаёт «Программа не установлена» на все три (`/api/providers/catalog` с :3778). Из терминала (:3777) всё находится. PATH нигде не восстанавливается; в окне для «не найдена» нет ни команды установки, ни «указать путь».

| № | Что | Исход «готово» |
|---|---|---|
| 1 | **PATH как у человека в терминале.** При старте движка, если PATH «голый» (нет `~/.local/bin`, `/opt/homebrew/bin`, `/usr/local/bin`), спросить PATH у логин-шелла пользователя один раз (`$SHELL -lc 'printf %s "$PATH"'`, таймаут 3 с, без интерактива) и добавить известные каталоги (`~/.local/bin`, `/opt/homebrew/bin`, `/usr/local/bin`, `~/.npm-global/bin`, `~/.volta/bin`, `~/.cargo/bin`, `~/.hermes/node/bin`, текущий nvm). Итоговый PATH — провайдерам и дочерним процессам; в трассу — где искали. Оболочка (main.js) передаёт движку тот же восстановленный PATH. | в .app из Finder каталог видит `codex`, `devin`, `claude`, если они есть у пользователя; тест: голый PATH + логин-шелл с `~/.local/bin` → найдено; шелл не ответил → известные каталоги |
| 2 | **Карточка «не нашли программу» — действенная:** «Не нашли codex. Искали в: …» + «Установить» (команда из каталога с кнопкой копирования и ссылкой на сайт программы) + «Указать путь к программе…» (пикер файла через preload — `pickFile`, рядом с существующим `pickFolder`); путь сохраняется в настройках владельца и каталог перечитывается; после этого «Подключить» = вход (TS-20). Элементы — сначала в дизайн-коде. | на чистом PATH человек за два клика доводит Codex до «вход выполнен»; указанный путь переживает перезапуск; неверный путь → «это не codex» словами |
| 3 | **Первый запуск** (TS-19) — та же карточка на шаге выбора программы. | проверено в .app с чистым `$HOME` |
| 4 | Отказ входа у найденной программы — по-прежнему словами с кнопкой «Подключить» (без кодов). | без регрессий TS-20e |

Правила: ничего не устанавливать за пользователя; команды установки — только из каталога программ (не выдумывать); секреты не трогать. Снимки 1440 — с живого окна (свой порт, не :3777 владельца) и запуск упакованного .app с голым PATH. Полный `npm test`.
