# TS-09b5 — Подсказки ролей из контекста разговора с оркестратором; ручное создание роли из предложения

Статус: слово владельца 11.10.2026 23:25 (снимок меню «Назначить роль» в проекте «Юристы 4114»: в составе есть роли, которых нет в списке классов, часть ролей вообще новые). Исполнитель — codex-worker после TS-09b3.1, раньше TS-18. Код сразу по строкам, одно ревью. Оркестратор: claude-orch.

## Опора
Права — только `kind` (закрытый список TS-09b1: orchestrator/assistant/architect/worker/reviewer/tester/researcher). Имя роли (`label`) и вводная (`intro`) — свободные, уже есть в предложении TS-09b3 (`seats:[{kind, label, vendor, model, mode, intro}]`, team-proposals.json, версии, подтверждение владельца).

| № | Что | Решение |
|---|-----|---------|
| 240 | раздел «Предложено в разговоре» | меню «Назначить роль» (композер, cx.js) показывает над классами раздел из последнего предложения текущего проекта (ожидающего или последнего подтверждённого): имя роли, класс прав, модель/вендор, режим, первая строка вводной; источник — `GET /api/seats/proposals` (есть по TS-09b3); обновление по SSE предложений |
| 241 | действия | «Подтвердить состав» → та же карточка подтверждения TS-09b3 (версия, точное подтверждение); «Создать эту роль» → новая дверь владельца `POST /api/seats/owner {proposalId, version, seatIndex}` — создаёт одно место из подтверждённой/подтверждаемой строки предложения с теми же sid/вводной, помечает строку как созданную владельцем, остальные остаются; повтор не создаёт дубль (ключ по proposalId+seatIndex) |
| 242 | новые роли и классы | любое имя роли допустимо; класс прав выбирается из закрытого списка (оркестратор указывает в предложении; владелец может сменить класс в карточке до создания); нового класса прав чат не создаёт — подпись «класс прав: один из семи», расширение списка — отдельное решение владельца |
| 243 | нет предложения | если оркестратор описал состав текстом, а предложения в хранилище нет (как при отказе инструмента до TS-09b3.1), раздел показывает честную подсказку «оркестратор описал состав, но не зарегистрировал предложение — попросите его: «зарегистрируй предложение»» и кнопку, которая отправляет эту фразу в чат оркестратора |
| 244 | тесты | DOM+HTTP: предложение с ролями вне списка классов → раздел с именами и классами; «Создать эту роль» дважды → одно место; смена класса до создания; нет предложения → подсказка и отправка фразы; поздний ответ после смены проекта не рисует чужой раздел; права места только по kind |

Пути: `ui/deploy/{cx.js,live.js,proto.css}`, `packages/api/src/routes-owner.ts` (+тест), `packages/runtime/src/proposals.ts` (+тест), `ui/sketches/disarto/00-design-code.html` (строка роли с классом).
