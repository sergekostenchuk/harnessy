## Правила серии
- Словарь — раздел `proxy-path-spec` дизайн-кода: прокси · VPS · «через что подключаемся» · «напрямую — сервис видит ваш адрес» · «если не ответит — через …» · «работает / не отвечает». Нет: выход, цепочка, маршрут, ретранслятор, привязка, revision, ID, ожидаемый IP, коды ошибок в заголовках.
- Сначала элементы в `00-design-code.html` (раздел proxy-path-spec дополняется), потом экран.
- Сдача — SHA + полный прогон + снимки 1440 каждого кадра, который задача покрывает, на дублёре. Оркестратор сам проходит путь на :3777 перед слиянием.
- Данные и HTTP движка не переименовываются; подписи и состав экранов — по скетчу. Старые настройки (выходы, цепочки) переносятся без потери.
- Живые вызовы и настоящие VPS — только по слову владельца.
