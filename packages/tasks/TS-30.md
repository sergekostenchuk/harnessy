# TS-30 — Упаковка: бинарник Harnessy для тестеров (macOS)

Статус: слово владельца 15.10.2026 «да». Оркестратор: claude-orch. Подпись/нотаризация и автообновления — TS-31; здесь — собираемое и запускаемое приложение.

## Факты
- Оболочка `ui/desktop` (Electron 44.4.1, `main.js` ждёт :3777 и запускает `run.sh` → `node packages/api/bin/harnessy.ts`); конфигурации сборки нет.
- Node внутри Electron 44 — 24.21.0, `node:sqlite` доступен (проверено `ELECTRON_RUN_AS_NODE=1`). Движок использует `node:sqlite` в runtime (limits-cache, network-stats, provider-limits).
- Пакеты строятся `npm run build` (workspaces); движок сейчас запускается из TS (type stripping, Node ≥ 22).
