# Простой чат с моделями Anthropic по подписке

Одна страница в браузере и маленький сервер на Node. Сервер ходит не в API,
а в локальный Claude Code CLI (`claude -p`), который залогинен твоей подпиской
Claude (Max). Ключ API не нужен, отдельный счёт не открывается.

Зависимостей нет. Нужен Node 22+ и установленный `claude`.

## Запуск

```bash
cd /Users/kostenchuksergey/projects/simple-claude-chat
node server.mjs
```

Открыть: http://localhost:3777

Другой порт: `PORT=4000 node server.mjs`.

## Вход по подписке (один раз)

Сервер использует вход CLI, а не приложения Claude. Если вверху страницы жёлтая
полоса «Вход по подписке не выполнен» — в Терминале:

```bash
claude login
```

Откроется браузер, войти в свой аккаунт Claude. После этого обновить страницу.
Проверить: `claude auth status` должен показать `"loggedIn": true`.

## Что умеет

- Выбор модели: Sonnet 5, Fable 5.1, Opus 5, Haiku 4.5.
- Ответ приходит потоком, по мере генерации.
- Разговор продолжается в одной сессии (память между сообщениями), «Новый чат»
  начинает новую. Текущий разговор переживает перезагрузку страницы
  (хранится в браузере).
- Внизу каждого ответа: модель, время, токены.

## Чего нет нарочно

- Инструментов у модели нет: файлы, команды, интернет недоступны.
  Это чистый чат.
- Хуки, MCP-серверы и CLAUDE.md пользователя в этот чат не попадают:
  сервер запускает `claude` с `--tools ""`, `--strict-mcp-config`,
  `--setting-sources ""` и своим коротким системным промптом, а сессии держит
  в `/Users/Shared/simple-claude-chat` (вне домашней папки, чтобы не подхватить
  `/Users/kostenchuksergey/CLAUDE.md`).

## Как это устроено

`server.mjs` — HTTP-сервер: `GET /` отдаёт `index.html`, `GET /api/status`
показывает вход и модели, `POST /api/chat` запускает один ход
`claude -p --output-format stream-json --resume <сессия>` и отдаёт текст
потоком (server-sent events). `index.html` — вся страница, без сборки.

Переменные: `PORT`, `CHAT_WORK_DIR` (папка сессий), `CLAUDE_BIN` (путь к
claude, если не найден сам).
