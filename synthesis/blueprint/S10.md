### 0.3 Схема сцены одной строкой

Вопрос извне → (нет ответа под рукой) → запрос агенту в чат → работа агента (модель, файлы, рендер) → материал в чате/файле → проверка «из 10» и на глаз → передача адресату вне харнесса → повторный вопрос → «посмотри снова» → дельта репликой. Система участвует **только** в середине (стадии 3–5 и 7); начало и конец сцены проходят мимо неё (`digest/S10.md` §1.2, по карте §1; [вывод]).

### 4.9 Сводка для IA: какие сущности и события нужны, чтобы паспорт сцены заполнялся сам

Перечислено только то, чего нет ни в одном источнике §4.1 [вывод по матрице]:

1. **Объект «внешний адресат»** (имя/роль: сестра, дизайнер, подписчики) и событие **«меня спросили»** с тремя вопросами адресата (где / когда / что до MVP) — вход F1.
2. **Объект «рассказ для внешнего адресата»** [термин-кандидат]: адресат · уровень L0/L1 · формат · дата среза (из Г/К) · статус (черновик / проверен / опубликован) · версия и дельта к предыдущей — закрывает F6, F16, D3 (R36).
3. **Утверждённая пользователем формулировка проекта на L0** (одна строка «зачем») и **словарь L0 для ступеней лестницы и рубежа** — без них ГДЕ/ЗАЧЕМ/ЧТО ОЖИДАЕМ остаются ◐ (F4, F7; `r2-transitions.md` F12).
4. **Событие «визит»** (пользователь вернулся) как якорь для дельты — вместо «хода» и «сессии» (кандидат №1; F13).
5. **Метка «подтверждено / не подтверждено» с происхождением** у каждой фразы о состоянии (файл, коммит, прогон, вердикт — Г, Пр, Р уже дают основания) и разделение AS-IS / TO-BE (F8; R21, R22; методика самого пользователя J9).
6. **Результат проверки на секреты/личное** и **подтверждение публикации** (шлюз публикации; F9, D5; R14, R25).
7. **Событие «показано адресату»** и **«реакция адресата»** (F12, W2) — единственный способ измерить успех сцены; сегодня [нет свидетельств].
8. **Признак «прочитано пользователем»** для материала (F11).
9. **История сопоставимых прогонов для калибровки «осталось»** — иначе КОГДА заполняется только elapsed и «пунктов до рубежа» (F3; C3).
10. **Тип тишины и здоровье датчика** как поле паспорта (F14, F17) — чтобы «где мы» не строилось на молчащем канале.
